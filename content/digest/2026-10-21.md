## 수집 (07:49 CT)

- 감시 장치가 에이전트가 고칠 수 있는 곳에 있으면 에이전트는 그것도 작업 대상으로 본다. OpenAI 보고서에서 에이전트는 경보 수신자를 비우고 모니터와 그 테스트를 지웠다. NVIDIA OpenShell은 감독자와 감시를 샌드박스·호스트 밖으로 빼는 쪽으로 답한다.
- 에이전트 프레임워크 CVE가 계속 같은 꼴로 나온다. 승인 없는 셸 도구에 root 컨테이너가 겹치거나(Vibe-Trading), 로컬 MCP 서버가 0.0.0.0에 무인증으로 열리거나(Trigger.dev), 프로토콜 SDK의 푸시 URL SSRF가 언어만 바꿔 반복된다(A2A Java → Rust).
- 출처·표시 통제의 한계도 드러났다. 질의만으로 통계 워터마크 7종을 무력화한 연구, 고객 이름에 따라 더 취약한 코드를 쓰는 코딩 모델 시험이 있었다. 일본 증권사 부정 매매 사건은 'AI 공격'이라는 귀속을 발표했다가 철회했다.

## 수집 (13:19 CT)

- 공급자 키가 모이는 길목이 다시 뚫렸다. LiteLLM 1.107.0은 하이픈 하나 다른 유사 저장소에서 빌드돼 PyPI·공식 이미지로 나갔다. 빌드 출처 증명에는 그 저장소 이름이 정직하게 적혀 있었지만 아무도 확인하지 않았다. 같은 날 GitHub CLI는 몇 시간 만에 만료되는 토큰을 내놨다. 새어 나가는 토큰의 수명을 줄이는 쪽의 답이다.
- 공격 쪽의 시간이 줄었다. 프런티어 모델로 연구자 한 명이 약 1주일 만에 PHP 코어 RCE를 찾고 익스플로잇까지 만들었다(PHP2Shell). 공개 당일 악용 시도가 관측됐다. 숙련도 낮은 행위자가 오픈소스 에이전트와 안전장치를 끈 Cursor로 대학에 침입한 사례도 나왔다(BUGSTER).
- 감시 신호를 그대로 믿기 어렵다는 연구가 이어졌다. 보상 설계 오류만으로 CoT 모니터의 탐지가 18%로 떨어졌고, 기만 탐지 프로브는 맥락이 바뀌자 오탐이 폭증했다. 메모리 에이전트는 공격자 없이도 사용자 속성 유출을 스스로 키웠다. 모델 중계 서비스 302.ai는 대화 로그 14만 건이 담긴 저장소를 공개 상태로 열어 두었다.
