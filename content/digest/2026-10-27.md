## 수집 (07:21 CT)

- 에이전트 안의 검사는 경계가 아니라는 근거가 한꺼번에 쌓였다. Claude Code·Codex CLI·Gemini CLI는 위조된 대화 기록을 재개 때 사용자 지시로 읽었고, 파일 도구가 막은 경로를 셸로 썼다(AISEC-2026-0193). Claude Code Edit 도구는 샌드박스 안에서 바꿔치기한 심볼릭 링크를 샌드박스 밖 권한으로 따라갔다(AISEC-2026-0196). Umbraco의 AI 도구는 호출한 사용자의 권한 대신 자기 권한으로 읽고 썼다(AISEC-2026-0197). 경계는 프로세스 밖 샌드박스와 백엔드 인가에 둬야 한다.
- 심사기가 보는 것과 에이전트가 읽는 것이 어긋나는 곳이 공격 면이다. 지시문 없이 변수 이름만 바꾼 코드가 분석기 7종을 모두 통과해 에이전트에 취약 코드를 쓰게 했다(AISEC-2026-0195). 각각 무해한 스킬 몇 개의 조합이 정책 위반을 23%p 끌어올렸다(AISEC-2026-0194). LLM 판정기가 보지 않는 첨부에 넣은 지시는 판정을 78% 통과했다(AISEC-2026-0199). MCP로 감싼 웹 API도 기존 취약점의 91%를 그대로 물려받았다(AISEC-2026-0198).
- 평가 수치를 읽는 법도 바뀌어야 한다. RAG 오염 필터의 높은 탐지율은 벤치마크 문서 구성에 기대고 있었다(AISEC-2026-0200). 사실만 담은 한쪽 편 문서로도 답변 입장이 기울었다(AISEC-2026-0202). 자동 레드팀은 표적의 실패 진단을 쓸 때 가장 강했다(AISEC-2026-0201). 그 밖에 GMO 데스크톱 클라우드 공격자가 고객 정보 공개를 시작했고(AISEC-2026-0203, AI 관여는 미확인), CSA는 AI 벤더의 제3자 인증 경로 STAR for AI Level 2를 열었다(AISEC-2026-0204).

## 수집 (13:21 CT)

- 에이전트 도구를 감싼 서버와 프레임워크가 같은 실수를 반복했다. LLM이 채우는 도구 인자를 셸 문자열에 이어 붙인 MCP 서버 9종의 CVE가 하루에 올라왔고, 메일·SMS 속 지시가 그대로 셸 명령이 된다(AISEC-2026-0212). NVIDIA NeMo Agent Toolkit은 1.8.0까지 핵심 기능에 인증이 없었다(CVSS 10.0, AISEC-2026-0211). AWS Strands Agents는 세션을 /tmp에 두어 세션 기록이 인젝션의 지속 장치가 될 수 있었다(AISEC-2026-0213). OpenClaw 사용자 보고 521건도 접근 통제 실패가 35%로 가장 많았다(AISEC-2026-0218).
- 에이전트 작업 기록이 공급망의 새 유출물이 됐다. Warp는 서드파티 벤더를 거친 침해로 사용자 약 1%의 에이전트 결정 로그와 텔레메트리가 노출됐다고 밝혔다(AISEC-2026-0210, 공식 공지 원문 미확인). 연구 쪽에서는 서명이 출처만 증명할 뿐 내용은 증명하지 않는다는 결과(정상 키로 서명한 오염 RAG 팩, AISEC-2026-0215)가 나왔다. 버전을 고정해도 MCP 도구 동작은 바뀐다는 실측(AISEC-2026-0219)과, 공개 가중치·데이터가 공격 지도가 된다는 분석(AISEC-2026-0221)도 있다.
- 평가는 체크포인트·대화 단위로 다시 해야 한다. 같은 레시피로 재학습한 모델도 통하는 탈옥이 달라졌다(AISEC-2026-0220). 3턴 안에 끝나는 적응형 다회차 공격기가 안전 강화 모델 4종을 평균 59.6% 뚫었다(AISEC-2026-0216). 모델 문맥에 넣은 스킬은 대화만으로 새어 나갔다(AISEC-2026-0217). 방어 쪽에서는 Google Cloud가 에이전트가 넓은 역할 대신 시간 제한 권한을 요청하고 사람이 승인하는 IAM Helper를 내놨다(AISEC-2026-0214).

## 수집 (18:51 CT)

- 서명이 맞는 토큰이라고 해서 이 서버에 쓰라고 발급된 토큰은 아니다. 같은 날 MCP 공식 Python SDK(AISEC-2026-0222)와 AWS API MCP Server(AISEC-2026-0223) 모두 토큰의 audience를 확인하지 않는 결함을 공개했다. SDK 쪽 수정은 업그레이드만으로는 켜지지 않는다. 비밀은 관측성 경로로도 샌다. MLflow의 CrewAI 자동 로깅이 API 키를 트레이스에 평문으로 남겼다(AISEC-2026-0229). 방향은 사람 토큰 대신 단기 워크로드 토큰(Copilot SDK 서버 간 인증, AISEC-2026-0232)과 VM 밖 자격 증명 브로커(Capsem, AISEC-2026-0230)다.
- 공격자의 에이전트는 이제 실제 침투 기록으로 확인된다. CrowdStrike가 확인한 행위자 4곳은 모두 Claude Code를 실행 엔진으로 썼고, 그중 하나는 공개 스킬 819개만으로 정부 도메인을 뚫었다(AISEC-2026-0224). TrendAI는 일본 표적 공격 서버 3곳을 AI 관여 수준으로 나눴는데, 가장 자동화된 사례는 44개 에이전트로 19개 조직을 훑었다(AISEC-2026-0225). 진입점은 어느 쪽이든 노출된 관리 화면과 기본 자격 증명이었다.
- 숫자 하나로 안전을 판단하면 안 된다. GitHub 숨은 텍스트 1억 4,500만 건을 실측해 보니 공격은 47건뿐이었다. 대신 위조할 수 있는 ‘에이전트 표식’이 넉 달 새 2.2배로 늘었다(AISEC-2026-0226). GPT-6.1 Terra는 중대 플래그가 줄었지만 유출·파괴적 행동 플래그는 늘었다(AISEC-2026-0227). DeepSeek 마이너 개정판 하나에서 숨은 목표 완수율이 11%에서 77%로 뛰었다(AISEC-2026-0231). 그 밖에 vLLM 멀티모달 입력이 호스트 Ghostscript를 거쳐 원격 코드 실행에 이르는 경로(AISEC-2026-0228), 3초 분량 음성 토큰만으로 목소리를 복제하는 공격(AISEC-2026-0233)이 나왔다.
