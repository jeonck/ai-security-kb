## 수집 (05:21 CT)

- 에이전트가 처음 읽는 것이 곧 공격 표면이다: IDE 마켓플레이스의 확장(AISEC-2026-0307), 스킬 마크다운(AISEC-2026-0312), 사전학습 데이터(AISEC-2026-0308) — 출처를 검증하기 어려운 층마다 실행 단계 격리·egress 통제가 마지막 방어선으로 남는다.
- 모델은 ‘누가 말했는지’를 라벨이 아니라 말투와 모양으로 판단한다. 도구 출력 속 가짜 사용자 턴에 최신 모델이 속고(AISEC-2026-0309), 이미지 탈옥은 점이 아닌 영역으로 퍼진다(AISEC-2026-0313).
- 평가 하네스 설정 하나가 능력을 숨긴다 — 일본 AISI 재평가에서 GLM-5.3 평균이 0.61에서 8.34로 뒤집혔다(AISEC-2026-0311). MCP OAuth 등록 창구를 열어 둔 WordPress 플러그인(AISEC-2026-0310)은 스펙 준수가 곧 안전은 아님을 보여 준다.

## 수집 (11:20 CT)

- 코딩 에이전트가 공격자의 손이 됐다. Aur0ra 랜섬웨어 제휴자는 VPN 계정과 목표만 주고 Cursor 에이전트에게 AD 정찰·자격 증명 공격·측면 이동을 맡겼다(AISEC-2026-0317). 정품 Codex·Claude Code CLI도 설정 한 줄로 제3자 릴레이를 거치게 되고 샌드박스까지 꺼졌다(AISEC-2026-0318). 바이너리 서명이 아니라 설정·목적지가 통제 지점이다.
- 에이전트가 ‘지시’로 읽는 입력면이 계속 넓어진다. 다른 팀의 에러 메시지·CI 로그(AISEC-2026-0319), README·TODO의 위치(AISEC-2026-0324), 스킬의 ‘묻지 말고 진행하라’ 한 줄(AISEC-2026-0322), CLAUDE.md(AISEC-2026-0325), 인용된 남의 대화(AISEC-2026-0323)가 그 예다. 사용자 칭찬만으로도 인젝션 저항이 깎인다(AISEC-2026-0321).
- 모델 쪽 방어는 신호일 뿐이다. 판정 확률을 그대로 내주는 가드레일은 범용 접미사에 뒤집히고(AISEC-2026-0326), 무해한 연속 튜닝도 정렬을 깎는다(AISEC-2026-0327). 그래서 근원 의존성 CVE로 다시 추적 가능해진 MCP OAuth 경로(AISEC-2026-0320)나 대화 단위 토큰 바인딩 초안(AISEC-2026-0328) 같은 실행 경로·신원 쪽 통제가 무게를 받는다.

## 수집 (17:19 CT)

- 자율 침투 도구가 국가 첩보 작전의 기본 장비가 됐다. VAPOR PANDA는 ARTEX로 11일 만에 14개국 200곳 이상을 동시에 두드렸는데(AISEC-2026-0329), 뚫린 곳은 새 취약점이 아니라 서명 없는 SAML, IMDS, 회수 안 된 키 같은 오래된 신원 결함이었다. 사고 대응 현장에서는 코딩 에이전트 토큰이 이미 탈취 대상 목록에 올라 있다(AISEC-2026-0330).
- ‘로컬이니까, 읽기 전용이니까 안전하다’는 가정이 연달아 깨졌다. 루프백에 묶인 MCP 서버도 브라우저가 들어오는 문이 되고(AISEC-2026-0331), 도구 수준 읽기 전용은 SQL 해석 차이 하나로 우회되며(AISEC-2026-0334), 에이전트 키로 바꿀 수 있는 설정 칸이 호스트 셸로 이어졌다(AISEC-2026-0333). 모델 하나를 내려받는 일이 플러그인·MCP 설정을 바꾸는 일이 되기도 한다(AISEC-2026-0332).
- 연구 쪽에서는 승인 단위와 평가 단위를 넓히라는 신호가 겹친다. 무해한 스킬끼리 얽히면 새는 길이 생기고(AISEC-2026-0335), 정화 방어는 검사 질의를 봉인해야 버티며(AISEC-2026-0336), 지속 학습은 출처 무결성 없이 거짓을 배운다(AISEC-2026-0337). 수십 달러짜리 자동 탈옥 탐색(AISEC-2026-0338), 추론 시간·체크포인트로 새는 학습 데이터 정보(AISEC-2026-0339, AISEC-2026-0340)도 같은 흐름이다.
