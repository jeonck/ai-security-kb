## 수집 (01:58 CT)

- 공격 비용 곡선이 꺾였다: OpenAI 파이프라인은 커널 LPE 하나를 약 1,279달러에 만들었고, ‘패치 안 된 시스템의 저권한 계정은 사실상 root’라는 주장은 커널을 공유하는 에이전트 샌드박스의 격리 가정을 직접 겨눈다.
- 막는 쪽의 상식이 연달아 흔들린다: 지시문이 없는 문서 조작은 인젝션 탐지에 안 잡히고, 서명과 egress 허용 목록을 모두 통과하는 MCP 도구가 허용 목적지로 데이터를 싣고 나간다. 대안으로 ‘계획과 실행의 분리’(Baya)와 ‘호출마다 깨끗한 복제본’(germline execution)이 나왔다.
- 성능 노브도 안전 경계다: MoE 전문가 수 축소, 컨텍스트 압축 같은 서빙 최적화가 정확도는 지키면서 거부 정렬을 깎는다. 서빙 설정 변경에 안전성 회귀 평가를 붙여야 한다는 근거가 쌓였다.

## 수집 (10:21 CT)

- 공격자는 하네스만 빌린다: BOSSAI 운영자는 상용 모델이 거부하자 Claude Code·Codex 같은 코딩 에이전트를 로컬 abliterated 모델에 연결해 썼고, 실제 침해는 기본 비밀번호·미패치 DB에서 나왔다. 동시에 그 공격 도구(ARTEX)의 비공식 이미지가 백도어로 운영자 자신을 노렸다 — 출처 없는 이미지는 공격자에게도 공급망 위험이다.
- ‘안전 모드’와 ‘샌드박스’라는 이름이 실제 경계를 보장하지 않는다: ChatGPT Lockdown Mode는 HTML 프리뷰 iframe 권한 한 줄로 뚫렸고, DB-GPT는 ‘이미 컨테이너 안’이라며 샌드박스를 껐으며, AgentScope는 헤더 이름표를 신원으로 믿고 MCP stdio 설정 저장을 곧 명령 실행으로 만들었다.

## 수집 (16:42 CT)

- 첫 공지의 범위는 믿을 수 없다: Chainalysis는 ‘세션 토큰 미노출’이라고 했다가 닷새 만에 전 사용자의 비밀번호 해시·유효 토큰 노출로 범위를 바꿨다. 유출 키 81%가 통지 6개월 뒤에도 살아 있었다는 Truffle의 수치와 겹쳐 보면, 기본 대응은 ‘조사 뒤 회수’가 아니라 ‘회수 먼저’여야 한다.
- 이름표는 신원이 아니다: IoA는 에이전트 이름만으로 접속을 받았고, mcp-go·ChatCLI는 상대 MCP 서버가 적어 낸 resource 값으로 토큰을 요청했으며, Dify 샌드박스는 공개된 기본 키로 문을 잠갔다. 모두 상대가 스스로 밝힌 값을 그대로 믿은 결과다.
- 막는 지점이 모델 밖으로 옮겨 간다: OpenAI는 거부를 줄인 GPT-6 Cyber를 신원 확인 등급 뒤에만 열었고, Microsoft는 로컬 에이전트를 OS 강제 경계(MXC)에 넣는 제품을 정식 출시했다. 반대로 ARTEX 운영자는 Claude Code 하네스를 재판매 중계로 DeepSeek에 붙여 공급자 쪽 탐지를 피했다.
