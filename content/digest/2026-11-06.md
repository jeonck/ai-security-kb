## 수집 (00:20 CT)

- 승인 버튼과 로그인 세션은 신원이 아니다: ThisBash는 요청을 보내는 쪽이 승인까지 눌렀고, SDNY 사건은 목소리·얼굴로 송금 승인을 받아 냈으며, 가짜 AI 행사 피싱은 진짜 Microsoft 기기 코드 화면으로 토큰을 넘겨받았다. 반대편에서는 Anthropic(관리 기기의 개인 계정 차단·IP 허용 목록)과 Google(OIDC 기반 Agent Identity JWT)이 신원을 정적 비밀 밖으로 옮기는 기능을 냈다.
- 유출 비밀의 반감기가 분 단위가 됐다: ARTEX는 GitHub 검색에서 Key Vault 유출까지 약 5분이었고, BlueFlag 수치로는 저장소 토큰 99%가 만료 없이 코딩 에이전트의 관리자 권한 신원에 묶여 있다.
- 인젝션 방어 연구는 ‘무엇을 말했나’에서 ‘누가 이 값을 정할 권한이 있나’로 옮겨 간다: 지시문 없는 과업 변조는 탐지·도구 정책을 통과하고, 대상 승인(SPILLWAY)과 서명 매니페스트는 효과가 크지만 서명 전 오염과 CoT 모니터 회피(TraceMRT)라는 빈틈이 남는다.

## 수집 (06:15 CT)

- 연동 토큰은 다리다: GitBook 침해는 SSO 결함 → 고객의 GitHub App → 저장소 속 Cloudflare 키 → 운영 비밀로 한 칸씩 건너 5시간 20분 만에 운영에 닿았고, 벤더 스스로 ‘AI 주도’라 평가했다. 같은 날 Censys는 ARTEX 공격 콘솔 1,465대를 세며 공격형 에이전트가 이미 대량 배포된 인프라임을 보여 줬다.
- 규제가 ‘에이전트 로그를 남겨라’로 구체화된다: 영국은 NIS 법안에 에이전트 통제 상실 시 행동 모니터링·피해 조직 통지·증거 보존을, 한국 과기정통부·KISA는 도구 호출·위임·외부 통신마다 검증하고 승인 피로를 탐지하라는 안내서를 냈다.
- 연구 쪽은 ‘방어가 통과시키는 것’을 잰다: 데이터 필터는 다중 턴 백도어 대화의 99% 이상을 통과시키고, weights_only=True는 체크포인트 속 두 번째 피클을 못 보며(Stanza), 모델 내부만 바꾼 추출 방어는 적응형 공격에 0%→100%로 무너졌다. 검색 관문 모델은 인젝션을 5.7%까지 낮추지만 0은 아니다.

## 기초 문헌 (12:19 CT)

- 우선순위 표의 남은 표준 3건(NIST SP 800-218A, NIST AI 100-2 E2025, OWASP Agentic Top 10)은 PDF 본문을 읽지 못해 이번에는 넣지 않았다. 대신 기초 문헌이 한 건도 없던 칸 세 곳을 원 논문으로 채웠다: 서빙×격리(간접 프롬프트 인젝션 원 논문), 공급망×격리(모델 허브 악성 모델 실측), 에이전트 런타임×출처(MCP 서버 생명주기 위협 분류).
- 세 논문의 공통 논지는 ‘데이터처럼 보이는 것이 코드로 실행된다’이다. 검색해 온 문서, pickle 모델 파일, MCP 서버의 도구 설명이 모두 그렇다. 필터·스캐너는 한 겹일 뿐이고, 격리와 서명·레지스트리가 경계가 된다.
