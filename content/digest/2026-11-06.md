## 수집 (00:20 CT)

- 승인 버튼과 로그인 세션은 신원이 아니다: ThisBash는 요청을 보내는 쪽이 승인까지 눌렀고, SDNY 사건은 목소리·얼굴로 송금 승인을 받아 냈으며, 가짜 AI 행사 피싱은 진짜 Microsoft 기기 코드 화면으로 토큰을 넘겨받았다. 반대편에서는 Anthropic(관리 기기의 개인 계정 차단·IP 허용 목록)과 Google(OIDC 기반 Agent Identity JWT)이 신원을 정적 비밀 밖으로 옮기는 기능을 냈다.
- 유출 비밀의 반감기가 분 단위가 됐다: ARTEX는 GitHub 검색에서 Key Vault 유출까지 약 5분이었고, BlueFlag 수치로는 저장소 토큰 99%가 만료 없이 코딩 에이전트의 관리자 권한 신원에 묶여 있다.
- 인젝션 방어 연구는 ‘무엇을 말했나’에서 ‘누가 이 값을 정할 권한이 있나’로 옮겨 간다: 지시문 없는 과업 변조는 탐지·도구 정책을 통과하고, 대상 승인(SPILLWAY)과 서명 매니페스트는 효과가 크지만 서명 전 오염과 CoT 모니터 회피(TraceMRT)라는 빈틈이 남는다.
