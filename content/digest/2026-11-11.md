## 수집 (21:54 CT)

- 격리·출처 통제의 ‘믿는 층’이 흔들렸다. TEE로 지킨다던 추론 요청이 그 안의 추론 엔진 RCE로 노출됐고(NEAR AI), 평가를 다 통과하는 모델도 뉴런 몇 개 편집으로 백도어가 될 수 있다(Lazarus). 결국 그 안에서 도는 코드와 가중치의 계보를 따로 검증해야 한다.
- MCP 인프라 자체가 공격 표면이 됐다. 게이트웨이·레지스트리의 SSRF·인가 누락(AWS mcp-gateway-registry), 문자열 정규화 한 번에 무너진 거부 목록(AWS API MCP Server), 고정했다고 믿은 MCP 서버가 실행마다 새 의존성을 받는 문제(Corelight)가 같은 날 나왔다.
- 공격 에이전트는 실전에, 방어 에이전트는 검증 병목에 있다. AntiFox가 실제 AWS 비밀 탈취에 쓰였고, Microsoft FORGE는 커널 CVE 33건을 찾았지만 병목은 패치 병합이었다. 연구는 LLM 판정기보다 결정적 가드가 낫다는 수치를 냈다.
