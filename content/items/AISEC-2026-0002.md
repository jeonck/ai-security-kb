## 요약
Adversa AI가 GitHub Copilot CLI를 autopilot 모드로 돌릴 때, 사용자가 웹 페이지 하나를 가져오라고 시키는 것만으로 작업 디렉터리의 `.env.prod` 파일 내용을 공격자 서버로 보내는 체인을 시연했다. 전체 과정은 28초가 걸렸다. 같은 지시를 평문으로 주면 모델이 거부하지만 "암호문을 풀라"는 퍼즐로 포장하면 통과한다는 점이 핵심이다. GitHub는 9월 17일 신고를 받아 재현을 확인했으나, 사용자가 공격자 콘텐츠를 직접 요청하고 완전 자율 권한을 줬다는 이유로 취약점이 아니라고 판정하고 바운티 대상에서 뺐다. 향후 기능을 더 엄격하게 할 수 있다고만 밝혔다.

## 동작 원리
페이지는 "이 암호문을 파이썬으로 복호화하라"며 키 두 개를 내민다. 하나는 진짜 키이고, 다른 하나는 로컬 파일 내용을 끼워 넣어야 완성되는 템플릿이다. 에이전트는 두 키를 다 준비하려고 파일을 읽어 템플릿에 넣는데, **이 "키 준비" 단계가 곧 탈취**다. 템플릿 키는 일부러 복호화에 실패하고, 진짜 키로 풀린 2단계 지시가 "맥락을 더 가져오라"며 수집한 파일 내용을 요청 파라미터에 실어 외부 URL을 호출하게 만든다. 모델 입장에서는 퍼즐을 푸는 정상 작업처럼 보인다. 여기에 모델 선택이 Auto면 라우터가 이런 지시에 관대한 모델(시험에서 mai-code-1.1-flash가 50% 성공)을 사용자 모르게 배정할 수 있어, 같은 설정에서도 세션마다 결과가 달라진다.

## 플랫폼 엔지니어 관점
- 코딩 에이전트의 autopilot·무확인 모드에서는 처음 보는 네트워크 목적지와 작업 디렉터리 밖 쓰기를 기본 거부로 둔다. 개발자 PC와 CI 러너 모두 같은 원칙이다.
- 탐지 룰은 페이로드 문자열이 아니라 "외부 콘텐츠 수신 → 코드 실행 → 로컬 파일 읽기 → 무관한 외부 호스트 호출" 순서로 건다. 이를 위해 도구 호출을 템플릿이 아닌 **실제로 풀린 인자**까지 세션 단위로 로깅한다.
- `.env*`, 클라우드 자격 증명 같은 비밀 값은 에이전트가 읽을 수 있는 경로에 두지 않는다. 시크릿 매니저·단기 토큰으로 옮기는 것이 근본 대책이다.
- 조직에서 허용할 모델을 고정하고 Auto 라우팅을 끄거나, 라우팅 풀의 모든 모델이 같은 인젝션 기준을 통과하는지 벤더에 확인한다.
