## 요약
OpenAI가 2026년 10월 5일 EU의 텍스트 출처 표시 규정에 대한 대응 방식을 공개했다. 발표 당일부터 전 세계 API 고객은 일부 모델에서 텍스트 워터마킹을 선택해 켤 수 있고(기본 꺼짐), 몇 주에 걸쳐 EU의 모든 요금제에서 대상 ChatGPT·Codex 텍스트 출력에 보이지 않는 워터마크가 들어간다. 검출기는 승인된 연구자·전문 기관에만 사례별로 열리며, 전 세계 기본값 적용은 출시 시점에는 하지 않는다. 배경은 EU AI Act 제50조 제2항으로, 합성 콘텐츠 생성 시스템 제공자에게 출력을 기계 판독 형식으로 표시하도록 요구하며 2026년 8월 2일부터 적용됐다(그 전에 출시된 시스템은 12월 2일까지 유예). OpenAI 발표문 자체는 조항 번호를 적지 않았다.

## 동작 원리
문장에 숨은 글자를 넣는 방식이 아니다. 모델이 다음 단어를 고를 때 비슷하게 그럴듯한 후보가 여럿 있으면, 비밀 키로 정한 규칙에 따라 그중 하나 쪽으로 살짝 기울인다. 사람이 읽기에는 자연스러운 문장 그대로지만, 키를 가진 검출기는 "우연이라기엔 키와 너무 잘 맞는 단어 선택"이 쌓였는지를 통계로 판정한다. 그래서 글이 길수록(200토큰 약 80%, 400토큰 약 95%) 잘 잡히고, 단어 선택의 여지가 적은 수학 풀이는 잘 안 잡힌다. 같은 이유로 단어를 바꾸는 편집에 약하다. 10%를 동의어로 바꾸면 92%가 66%로, 25%를 바꾸면 17%로 떨어진다. 결국 이 워터마크는 "OpenAI 모델이 관여했다"는 약한 신호일 뿐이고, 없다고 사람이 쓴 글이라는 뜻은 아니다.

규제 쪽에서 보면, 제50조 제2항은 제공자가 출력에 기계가 읽을 수 있는 표시를 달라는 의무다. 위원회는 이를 돕는 자율 행동강령을 2026년 6월 10일 최종 공개했고(제50조 의무는 8월 2일부터 적용), OpenAI는 검출기 접근도 이 행동강령의 틀 안에서 사례별로 허용한다고 했다.

## 플랫폼 엔지니어 관점
- EU 사용자에게 서비스하는 사내 도구가 ChatGPT·Codex 출력을 받아 쓰면, 그 텍스트에 워터마크가 들어간다는 사실을 데이터 처리 기록과 고객 고지 검토 목록에 올린다. 출력 품질 영향은 OpenAI 벤치마크상 미미하다고 하지만, 자체 회귀 평가 묶음으로 한 번 확인해 두는 것이 안전하다.
- API로 모델을 서빙·재판매하는 플랫폼이라면 워터마킹이 기본 꺼짐의 선택 기능이라는 점이 중요하다. EU에 합성 텍스트를 내보내는 제품이면 제50조 제2항 의무는 제공자에게 있으므로, 어떤 모델·엔드포인트에서 워터마크를 켰는지를 배포 설정(예: 모델 게이트웨이 정책, Helm 값)으로 관리하고 감사 로그에 남긴다.
- 워터마크를 "AI 생성 탐지" 통제로 과신하지 않는다. 짧은 텍스트, 편집·번역된 텍스트, 다른 공급자 모델 출력은 빠져나가므로, 코드 리뷰 정책이나 콘텐츠 정책에서 워터마크 부재를 사람이 썼다는 근거로 쓰지 않는다.
- 오픈 가중치 모델을 자체 서빙하는 경우 EU 대상 서비스라면 같은 의무가 자사에 걸릴 수 있다. 서빙 계층에 출력 표시 기능을 넣을 자리(추론 서버 플러그인, 게이트웨이 후처리)를 미리 설계해 두자.
