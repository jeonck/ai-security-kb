## 요약
HiddenLayer가 2026년 5월 7일, OpenAI의 Privacy Filter 공개를 사칭한 Hugging Face 저장소 `Open-OSS/privacy-filter`에서 악성 코드를 찾았다. 모델 카드는 원본을 거의 그대로 베꼈고, README가 `start.bat`이나 `loader.py`를 실행하라고 안내해 Windows에 Rust 기반 인포스틸러를 설치시켰다. 저장소는 18시간이 안 돼 트렌딩 1위, 다운로드 약 24.4만 회를 기록했지만 HiddenLayer는 이 수치가 조작된 것으로 봤다. 같은 로더를 쓴 저장소 6개가 다른 계정(anthfu)에서 나왔고, 인프라가 npm 타이포스쿼팅 캠페인과 겹쳐 더 큰 공급망 작전의 일부일 가능성이 제기됐다. 신고를 받은 Hugging Face는 이용 약관 위반으로 저장소를 삭제했다.

## 동작 원리
공격 벡터는 모델 가중치가 아니라 "README가 실행하라고 시킨 로더 스크립트"다. 그럴듯한 모델 카드와 부풀린 인기 지표가 신뢰를 만들고, 사용자가 스스로 스크립트를 돌리게 만든다. `loader.py`는 정상 로더처럼 보이는 미끼 코드를 먼저 돌린 뒤, 공개 JSON 저장 서비스에서 명령을 받아 숨긴 PowerShell로 실행한다. 명령이 저장소 밖에 있어 공격자는 저장소를 건드리지 않고 페이로드를 갈아 끼울 수 있다. 이후 단계는 관리자 권한 상승, Defender 예외 추가, Edge 업데이트로 위장한 일회용 예약 작업으로 SYSTEM 실행을 이어 가고, 흔적을 줄이려고 그 작업을 바로 지운다.

## 플랫폼 엔지니어 관점
모델도 패키지처럼 승인된 출처·버전만 들어오게 하는 내부 레지스트리(프록시) 게이트를 두고, 다운로드 수나 트렌딩 순위를 신뢰 근거로 쓰지 말자. 저장소에 딸린 `.py`·`.bat` 같은 실행 파일은 가중치와 분리해 검토하고, 새 모델을 처음 돌릴 때는 자격 증명과 브라우저 세션이 없는 격리 환경(빌드 러너·devcontainer·샌드박스 노드)에서 하자. 기존 SCA 도구는 의존성 매니페스트 중심이라 이런 로더 로직을 잘 못 잡는다는 지적이 있다(CSO Online 인용 분석가). 이미 실행한 PC가 있다면 재설치, 저장된 자격 증명과 세션 전부 폐기, 공개된 IOC 도메인의 egress 차단과 과거 프록시·DNS 로그 헌팅까지 한 세트로 처리한다.
