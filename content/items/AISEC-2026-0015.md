## 요약
Noma Labs가 Claude Code Desktop의 프리뷰 창이 악성 HTML을 렌더링하면서 숨긴 JavaScript를 실행해 개발자 PC의 자격 증명을 빼낼 수 있었던 취약점 "SneakPeek"을 10월 14일 공개했다. 공격자는 평범한 프로젝트처럼 보이는 저장소에 256KB가 넘도록 부풀린 커버리지 리포트를 넣어 두고, 피해자가 Claude에게 이 리포트를 봐 달라고 하면 추가 승인 없이 페이로드가 돈다. 노린 대상은 SSH 키, AWS·Kubernetes·Docker 레지스트리 자격 증명, npm·GitHub 토큰이었다. Anthropic은 CVSS 4.0 8.7(High)로 판정했고, 첫 패치가 우회된 뒤 8월 17일 Claude Desktop 1.30096.1에서 완전히 고쳤다. 공개 시점에 CVE는 아직 없었다.

## 동작 원리
프리뷰 창에는 세 겹의 방어가 있었다. 스크립트를 막는 CSP, 페이지를 "어느 출처도 아닌 곳"으로 만들어 로컬 파일을 못 읽게 하는 data: URL 로딩, 그리고 file:// 요청을 막는 필터다. 문제는 이 방어가 **파일 크기에 따라 다른 길**을 탔다는 점이다. 256KB를 넘는 HTML은 임시 파일로 저장돼 file:// 주소로 열렸고, 이 길에는 CSP가 없었으며 요청 필터도 개발 서버 프록시 때만 켜졌다. 결국 파일을 크게 부풀리기만 하면 스크립트가 로컬 파일을 같은 출처로 자유롭게 읽을 수 있었다. 첫 패치가 메인 페이지의 file:// 요청을 막자, 연구진은 blob: URL로 만든 Web Worker에서 요청을 보내 필터가 보지 않는 맥락으로 옮겨 다시 우회했다. "열어 보기만 했다"는 사용자 감각과 달리, 미리보기는 코드 실행이었다.

## 플랫폼 엔지니어 관점
- MDM·엔드포인트 관리로 개발자 PC의 Claude Desktop 버전을 1.30096.1 이상으로 강제하고, 자동 업데이트가 꺼진 단말을 찾는다.
- 에이전트 앱의 미리보기·렌더링 기능도 코드 실행 경로로 본다. 신뢰할 수 없는 저장소는 자격 증명이 마운트되지 않은 devcontainer·원격 개발 환경에서 연다.
- 개발자 PC에 장기 자격 증명(`~/.ssh`, `~/.aws/credentials`, `~/.kube/config`, `~/.npmrc`)을 두지 않도록 SSO·단기 토큰·하드웨어 키 기반으로 옮긴다. kubeconfig는 OIDC 단기 토큰으로 바꾼다.
- 조직에서 쓰는 AI 코딩 도구를 목록화하고, 각 도구의 렌더링·실행 격리 방식을 도입 심사 항목에 넣는다.
