## 요약
미 국토안보부(DHS)가 연방조달공급망보안법(FASCSA)에 근거한 장관 명령을 2026년 10월 20일 연방관보(91 FR 66346)에 공고했다. 명령은 Hangzhou DeepSeek Artificial Intelligence와 계열사가 개발한 IT 제품·서비스를 연방 민간기관의 조달에서 배제하고, DeepSeek·계열사 제품과 DeepSeek 구현으로 만든 서드파티 제품·서비스를 기관 IT에서 제거하도록 한다. 명령은 연방조달보안위원회(FASC)의 권고를 검토해 내려졌고, 서명된 명령서는 관보 부록과 regulations.gov 도켓에 실렸다. CyberScoop은 명령 서한이 6월 26일자로 이미 수개월째 시행 중이었고, 예외는 60일 전에 강한 사유와 함께 신청해야 한다고 보도했다. 기존 다이제스트에서 "서드파티 제품 포함 여부는 해석이 엇갈린다"고 적었던 부분은, 관보 공고가 제거 대상에 DeepSeek 구현 기반 서드파티 제품을 명시하고 있어 정정한다.

## 동작 원리
FASCSA는 특정 공급자를 "공급망 위험"으로 지정해 연방 정부 전체의 구매와 설치를 한 번에 막는 장치다. FASC라는 부처 간 위원회가 위험을 검토해 권고하고, 민간기관에 대해서는 국토안보부 장관이 명령을 낸다. 명령은 두 종류다. 앞으로 사지 말라는 배제 명령과 이미 들어온 것을 걷어 내라는 제거 명령이다. 이번 건은 둘을 함께 걸었고, 제거 쪽은 DeepSeek가 직접 만든 제품뿐 아니라 DeepSeek 구현을 써서 만든 남의 제품까지 겨냥한다. 기관 입장에서는 "우리 시스템 어디에 DeepSeek가 들어 있나"를 먼저 알아야 이행할 수 있다. CISA가 기관에 CDM 같은 자산 가시성 도구로 내장 시스템과 계약업체까지 훑으라고 안내하는 이유다. 모델이 패키지처럼 공급망의 한 품목이 됐다는 뜻이다.

## 플랫폼 엔지니어 관점
- 연방 고객이나 FedRAMP 환경을 상대한다면 서비스·도구 체인에서 DeepSeek 계열 모델을 쓰는 곳을 목록화한다. API 호출뿐 아니라 자체 서빙하는 오픈 가중치 모델, 파인튜닝 기반 모델, 서드파티 SaaS가 내부적으로 쓰는 모델까지 포함한다. 공고는 서드파티의 범위를 정의하지 않으므로 보수적으로 잡는다.
- 모델을 SBOM처럼 관리하는 AI-BOM을 배포 파이프라인에 넣는다. 모델 레지스트리에 공급자·기반 모델·가중치 해시를 기록하고, Kubernetes 배포 시 admission 정책으로 승인되지 않은 기반 모델 이미지·가중치를 막으면 조달 배제 명령이 나와도 영향 범위를 바로 뽑을 수 있다.
- 제거 기간에는 CyberScoop이 전한 권고처럼 해당 워크로드의 egress 트래픽 감시, 로깅 강화, 유출 통제를 우선 적용한다. 외부 DeepSeek API 도메인으로 나가는 egress를 차단 목록에 올려 두는 것도 간단한 1차 대응이다.
- 조달·구매 단계에도 확인 절차를 둔다. 새 AI 도구·SaaS 도입 시 기반 모델 공개 여부를 체크리스트에 넣고, 연방 사업이라면 SAM의 공급망 명령 목록을 확인한다.
