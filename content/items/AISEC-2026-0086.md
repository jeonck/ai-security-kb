## 요약
Anthropic이 2025년 12월 공개한 에이전트 확장 형식 Agent Skills를 Linux Foundation 산하 Agentic AI Foundation(AAIF)에 기증했다. MCP에 이어 두 번째로 중립 재단에 넘긴 표준이다. 기증 대상은 이름·로고, GitHub 조직, agentskills.io 도메인이며, 여러 회사 엔지니어가 개인 자격으로 유지보수를 맡는다. 발표 기준으로 70개 넘는 플랫폼이 이 형식을 쓰고 스킬 100만 개가 약 2억 8천만 회 설치됐다. 로드맵에 ‘스킬 작성·설치자용 보안 지침’이 올라 있지만 현재 명세에는 서명·출처·권한 모델이 없다.

## 동작 원리
스킬은 SKILL.md(이름·설명·지시문)와 선택적인 scripts/·references/·assets/ 폴더로 된 디렉터리다. 에이전트는 시작할 때 모든 스킬의 이름·설명만 읽고, 작업이 설명과 맞으면 본문 지시문을 불러와 따르며 필요하면 동봉된 스크립트를 실행한다. 즉 스킬 하나를 설치하는 것은 ‘에이전트가 스스로 판단해 언제든 읽고 실행할 수 있는 지시문+코드 묶음’을 들이는 일이다. 명세가 정한 신뢰 관련 장치는 실험적 필드 allowed-tools(사전 승인 도구 목록) 정도이고, 그나마 구현마다 지원이 다르다. 표준 검증 도구도 형식만 본다. 패키지 생태계로 치면 레지스트리 서명·출처 증명 없이 설치 수가 수억 회에 이른 상태다.

## 플랫폼 엔지니어 관점
- 스킬을 MCP 서버·npm 패키지와 같은 서드파티 코드로 분류해 승인 목록(내부 미러 저장소)에서만 설치하게 하고, 커밋 해시로 고정한다.
- allowed-tools는 스킬 저자가 스스로 선언하는 값이다. 에이전트 쪽 정책(실행 허용 명령·네트워크 egress)으로 덮어쓰고, 스킬 선언만으로 도구가 사전 승인되지 않게 클라이언트 설정을 확인한다.
- scripts/가 있는 스킬은 CI에서 정적 검사·비밀 탐지를 돌리고, 실행은 자격 증명이 없는 샌드박스에서 하게 한다.
- AAIF 로드맵의 보안 지침이 나오면 내부 스킬 저장소 정책(서명·메타데이터 필수 필드)을 그에 맞춰 갱신할 수 있도록 추적한다.
