## 요약
오픈소스 자율 에이전트 프레임워크 Agent Zero의 웹 UI 저장형 XSS에 CVE-2026-97635가 부여됐고, CISA가 조정자로 10월 22일 권고 VA-26-296-01을 공개했다. 1.15 미만 버전은 채팅 메시지와 첨부 파일 내용을 정화하지 않고 렌더링해, 악성 HTML이 든 대화나 파일을 열람하는 순간 사용자의 인증된 세션에서 스크립트가 실행된다. 제보는 1월에 들어왔지만 이슈는 응답 없이 자동 종료됐고, 수정은 이후 1.15 릴리스의 ‘채팅 마크다운 렌더링 XSS 수정’으로 들어갔다. CVE 공개는 수정보다 몇 달 늦었다.

## 동작 원리
에이전트 UI는 모델 응답과 사용자 입력을 보기 좋게 마크다운으로 그려 준다. 마크다운 렌더러가 HTML 태그를 그대로 통과시키면, 대화 기록이나 첨부 파일, 공유된 대화 JSON 안에 숨긴 스크립트가 화면에 그려지는 순간 브라우저에서 실행된다. 일반 웹 앱이라면 세션 탈취·피싱 정도지만, Agent Zero 같은 에이전트는 코드 실행·브라우저 조작 도구를 갖고 있으므로 같은 세션에서 에이전트에게 지시를 보낼 수 있다면 피해가 에이전트 권한 전체로 커질 수 있다(이 연결은 권고에 명시되지 않은 추론이다). 신뢰할 수 없는 텍스트가 모델을 거치든 사용자 업로드로 오든 결국 ‘렌더링’이라는 실행 경로를 지난다는 점이 핵심이다.

## 플랫폼 엔지니어 관점
- 사내에 Agent Zero를 배포했다면 1.15 이상으로 올리고, 외부에서 받은 대화 JSON·첨부 파일을 불러오지 않도록 공지한다.
- 에이전트 관리 UI는 인터넷에 노출하지 말고 SSO 뒤에 두며, 엄격한 CSP(인라인 스크립트 금지)를 리버스 프록시에서 강제한다. UI 세션 쿠키와 에이전트 도구 실행 권한을 분리한다.
- 에이전트 플랫폼을 고를 때 마크다운·HTML 렌더링 정화 방식(허용 목록 기반 sanitizer 사용 여부)을 보안 검토 항목에 넣는다.
- 오픈소스 에이전트 프로젝트의 보안 이슈가 자동 종료(stale bot)로 묻히는 사례이므로, 의존하는 프로젝트의 보안 이슈 처리 상태를 SBOM·의존성 위험 평가에 반영한다.
