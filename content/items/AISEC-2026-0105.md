## 요약
추론 모델에게 끝없이 생각하게 만드는 프롬프트를 넣으면 응답 하나에 수만 토큰이 쓰여 지연과 비용이 폭증한다. 기존 자동 탐색 공격이 찾은 프롬프트는 희귀 문자가 뒤섞인 이상한 문자열이라 펄플렉시티 필터로 쉽게 걸러졌다. 연구진은 탐색 공간을 확산 언어 모델에 연결해 같은 탐색 절차로 짧고 평범한 영어 요청을 만들어 냈다. 그 결과 프롬프트는 자연스러워졌고 펄플렉시티 필터·Llama Guard·프롬프트 인젝션 가드의 탐지율이 모두 떨어졌다. 상용 API 모델 두 종을 포함한 10개 대상 중 9개에서 과잉 생성이 일어났다.

## 동작 원리
공격 탐색기는 숫자 벡터를 고르고 그것을 문장으로 바꿔 대상 모델에 던진 뒤 응답 길이로 점수를 매긴다. 예전에는 벡터를 문장으로 바꾸는 장치가 무작위 대응표라 결과가 외계어처럼 나왔다. 이 대응표를 언어를 배운 확산 모델로 바꾸면 같은 벡터 공간에서도 사람이 쓴 듯한 문장이 나온다. ‘이상하게 생긴 입력은 공격’이라는 탐지 가정을 정면으로 깬다. 또 측정 도구에 따라 어떤 모델이 더 안전해 보이는지가 열 배 넘게 뒤바뀌므로, 위험 평가 결과 자체가 공격 생성기에 의존한다.

## 플랫폼 엔지니어 관점
- 추론 모델 엔드포인트에는 요청당 최대 출력·추론 토큰과 시간 상한을 강제하고, 테넌트별 토큰 예산·속도 제한을 게이트웨이에 둔다.
- 입력 펄플렉시티 필터를 자원 고갈 공격의 주 방어로 쓰지 않는다. 대신 응답 길이·추론 토큰 수 분포의 이상치를 사용자·키 단위로 탐지해 경보한다.
- 모델을 비교·선정할 때 공급자가 낸 과잉 생성 위험 수치를 그대로 믿지 말고, 서로 다른 공격 생성기로 자체 측정해 순위가 바뀌는지 확인한다.
