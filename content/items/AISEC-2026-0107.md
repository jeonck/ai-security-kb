## 요약
자기 증류는 별도 교사 모델 없이, 정답을 본 자기 자신이 교사가 되어 정답을 못 본 자신을 가르치는 후처리 학습 방식이다. 연구진은 이 방식이 프라이버시 관점에서 검토되지 않았다고 보고, 어떤 문제가 학습에 쓰였는지를 알아내는 멤버십 추론 공격 OP-Print를 만들었다. 기존 공격 기법은 이 모델들 앞에서 동전 던지기 수준이었지만 OP-Print는 그레이박스·블랙박스 모두에서 신호를 잡아냈다. 효과 크기는 아직 크지 않지만(AUC 0.55~0.61), 새 학습 기법마다 고유한 유출 흔적이 생긴다는 점을 보였다.

## 동작 원리
자기 증류에서 학습 신호는 응답 전체에 고르게 퍼지지 않고, 모델이 머뭇거리는 몇몇 지점에 몰린다. 학습에 쓰인 문제에서는 그 지점에서 교사 관점과 학생 관점의 차이가 이미 줄어 있다. 그레이박스 공격은 이 차이를 직접 재고, 블랙박스 공격은 답을 중간에서 끊고 다시 생성시켜 매번 같은 길로 가는지를 본다. 시험 문제를 미리 풀어 본 학생은 중간에 끊겨도 같은 풀이로 돌아오는 것과 같다.

## 플랫폼 엔지니어 관점
- 사내·고객 데이터로 자기 증류·온폴리시 증류를 돌리는 학습 파이프라인은 기존 미세 조정과 같은 수준으로 멤버십 추론 감사를 실행하고, 기존 손실 기반 감사 도구가 무작위 수준으로 나온다고 안전하다고 판정하지 않는다.
- 학습 데이터에 민감 정보가 있으면 증류 결과 모델의 배포 범위(내부 전용·외부 API)와 생성 재시작이 가능한 API 기능(접두 지정 생성 등)을 제한한다.
- 모델 카드·데이터 계보 기록에 사용한 후처리 학습 방식을 남겨, 새 공격이 나왔을 때 영향받는 모델을 찾을 수 있게 한다.
