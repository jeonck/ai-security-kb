## 요약
AWS가 2026-10-23 보안 공지로 관리형 AWS MCP Server의 run_script 도구 결함(CVE-2026-115845)을 공개했다. run_script는 에이전트가 AWS API를 호출하는 파이썬 스크립트를 샌드박스에서 돌리는 도구인데, 실행 전 스크립트를 걸러 내는 검증기의 금지 입력 목록이 불완전해 조작된 스크립트로 임의 코드를 실행할 수 있었다. 다만 실행은 공격자 자신의 격리 세션 안으로 한정됐고 인증이 필요했다. AWS가 서비스 측에서 고쳤기 때문에 고객이 할 일은 없다.

## 동작 원리
검증기는 ‘반입 금지 물품 목록’을 들고 선 보안 검색대다. 목록에 없는 방식으로 같은 일을 하는 코드(다른 모듈 경로, 동적 import, 문자열 조합 등)를 생각해 내면 통과한다. 파이썬처럼 표현력이 큰 언어에서 금지 목록으로 위험 코드를 다 막기는 사실상 어렵다. 이번에 피해가 세션 안에 머문 것은 검증기 덕분이 아니라 그 뒤에 있던 세션 격리라는 두 번째 벽 덕분이다. 공지는 구체 우회 기법을 밝히지 않았다.

## 플랫폼 엔지니어 관점
- 사내 MCP 서버나 에이전트 도구가 ‘코드 실행’을 제공하면 정적 검증기·금지 목록을 1차 방어로만 보고, 실제 경계는 세션별 일회용 컨테이너·microVM, 최소 권한 자격 증명, egress 제한으로 만든다.
- 코드 실행 도구에 주는 AWS 자격 증명은 세션 단위 단기 자격 증명과 좁은 IAM 정책으로 제한해, 검증기가 뚫려도 할 수 있는 일이 그 권한을 넘지 않게 한다.
- 관리형 MCP 서비스를 쓸 때는 벤더 공지 구독과 CloudTrail 기반 이상 호출 탐지를 운영 체크리스트에 넣는다. 이번 건은 고객 조치가 없지만, 같은 구조의 자체 구현은 스스로 고쳐야 한다.
