## 요약
보안 회사 Forever Security는 고객 환경에서 코딩 에이전트가 오래된 악성 npm 캠페인의 패키지 function-color를 설치하려는 것을 막았다. 지시의 출처는 사용자의 ~/Downloads 폴더에 들어 있던 AGENTS.md 파일이었고, 사용자는 바로 그 폴더를 작업 디렉터리로 에이전트를 띄웠다. 연구진은 격리 VM에서 같은 방식을 재현해 Codex가 전역 설정에 악성 MCP 서버를 등록하고 90% 이상 악성코드를 실행하는 것, Claude Code가 약 절반의 확률로 API 주소를 공격자 서버로 바꿔 OAuth 토큰을 넘기는 것을 보였다. 연구진은 두 제품 모두 설계대로 동작했을 뿐 패치할 버그는 없다고 본다.

## 동작 원리
코딩 에이전트는 작업 폴더에 있는 AGENTS.md·CLAUDE.md를 ‘이 프로젝트의 운영 지침’으로 읽는다. 한편 브라우저는 웹 페이지가 내려보낸 파일을 대개 묻지 않고 ~/Downloads에 저장하고, 실행 파일이 아닌 마크다운은 운영체제의 경고 대상도 아니다. 그래서 ‘다운로드 폴더에서 에이전트를 켠다’는 흔한 습관 하나만 있으면, 웹에서 떨어진 마크다운이 실행 파일과 같은 효력을 갖는다. 쪽지 한 장을 책상에 올려 두면 성실한 비서가 그대로 따르는 구조다. 지시 파일은 직접 코드를 실행하지 않지만 에이전트가 자기 권한으로 패키지를 설치하고, 설정 파일(~/.codex/config.toml, .claude/settings.json)을 고쳐 다음 세션까지 살아남는 거점을 만든다. Claude Code 사례에서는 API 주소를 바꿔 공격자가 ‘모델’ 자리에 앉으므로, 모델의 판단과 상관없이 샌드박스를 끈 도구 호출을 직접 내려보낼 수 있다. 에이전트가 스스로 브라우저를 여는 세션에서는 사람이 다운로드를 볼 기회조차 없다.

## 플랫폼 엔지니어 관점
- 개발자 단말 정책: 홈·~/Downloads·넓은 상위 폴더를 에이전트 작업 디렉터리로 쓰지 못하게 한다. 에이전트 래퍼나 관리 설정에서 ‘신뢰된 프로젝트 루트(저장소 루트)’만 허용하고, 처음 보는 폴더의 지시 파일은 사람 확인을 거치게 한다.
- 설정 무결성: ~/.codex/config.toml의 [mcp_servers.*] 블록, .claude/settings.json의 ANTHROPIC_BASE_URL을 EDR·파일 무결성 감시 대상에 넣고, 기업 관리 설정(managed settings)으로 API 엔드포인트와 MCP 서버 목록을 고정한다. 에이전트가 자기 설정을 고치는 동작은 승인 대상으로 둔다.
- egress: 에이전트의 모델 API 트래픽을 승인된 엔드포인트(사내 AI 게이트웨이)로만 나가게 하면 base URL 변조가 토큰 유출로 이어지지 않는다.
- 패키지 경로: 에이전트가 설치하는 npm·PyPI 패키지는 사내 프록시·쿨다운·허용 목록을 거치게 하고, function-color 설치를 침해 지표로 탐지한다.
- CI·원격 에이전트 플랫폼: 작업 공간에 외부에서 들어온 지시 파일(AGENTS.md, CLAUDE.md, .cursorrules 등)이 있으면 로딩 전에 검토하는 단계를 둔다.
- 사고 대응: 의심 시 에이전트 OAuth 토큰·API 키를 회수하고, 지시 파일이 바꾼 전역 설정을 원복한다.
