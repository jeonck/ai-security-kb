## 요약
오픈소스 코딩 에이전트 Continue의 최종 버전 2.0.0에서 MCP 서버 연결을 설정하는 함수(MCPManagerSingleton.setConnections)를 통해 OS 명령이 주입될 수 있다는 CVE-2026-116109가 2026-10-26 NVD와 GitHub Advisory Database에 게시됐다. CNA는 VulDB이고, 익스플로잇이 공개됐으며 벤더가 사전 연락에 답하지 않았다고 기록됐다. CVSS v4 점수는 2.1로 낮고 GitHub 검토 전 상태라 실제 위험도는 아직 판단하기 이르다. 다만 Continue 저장소는 이미 읽기 전용으로 전환돼 유지보수가 끝났기 때문에 패치 버전이 나올 가능성이 낮고, 3만 6천여 개의 별을 받은 도구라 IDE 확장으로 깔려 있는 개발자 PC가 많을 것으로 보인다.

## 동작 원리
MCP 클라이언트는 stdio 방식 MCP 서버를 쓸 때 설정에 적힌 ‘서버 실행 명령’과 인자로 하위 프로세스를 띄운다. 즉 MCP 서버 목록을 바꿀 수 있는 사람은 사실상 개발자 PC에서 실행될 명령을 고를 수 있다. 권고는 이 연결 설정 경로에서 명령 구성 요소가 제대로 정화되지 않아 임의 명령이 끼어들 수 있다고 본다. 비유하면 ‘전화번호부에 번호 대신 명령을 적어 두면 전화를 거는 순간 그 명령이 실행되는’ 구조다. 권고가 수동적 사용자 상호작용(UI:P)을 요구한다고 표기해, 개발자가 무언가를 열거나 불러올 때 터지는 시나리오에 가깝지만, 입력이 어디서 오는지는 원 항목을 열지 못해 확인하지 못했다.

## 플랫폼 엔지니어 관점
- 사내 개발자 PC·원격 개발 환경의 VS Code·JetBrains 확장 인벤토리에서 Continue를 찾아 내고, 유지보수가 끝난 에이전트 확장은 대체 도구로 옮기는 일정을 잡는다. 패치가 나오지 않는 도구는 CVE 점수와 무관하게 제거 대상으로 분류한다.
- MCP 서버 정의(명령·인자)는 저장소나 사용자 설정이 아니라 플랫폼 팀이 관리하는 허용 목록에서만 오도록 한다. 저장소 안의 에이전트·MCP 설정 디렉터리는 CODEOWNERS로 보안 리뷰어에게 묶는다.
- 코딩 에이전트는 devcontainer·원격 샌드박스 안에서 돌리고, 호스트의 SSH 키·클라우드 자격 증명을 마운트하지 않는다. IDE·에이전트 프로세스의 자식 프로세스 생성(셸, curl, 패키지 설치)을 EDR 규칙으로 감시한다.
- 확장 허용 정책에 ‘저장소가 archived/read-only로 바뀐 확장은 자동 경고’ 규칙을 추가한다.
