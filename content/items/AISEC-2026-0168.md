## 요약
CreditNirvana의 ‘Agentic AI Call Centre’(AI 에이전트 기반 콜센터 앱. 같은 회사는 추심 플랫폼 CollectionWorkz도 만든다)가 정적 API 키를 브라우저에 내려주는 JavaScript 번들에 넣어 배포했다. 누구나 웹 페이지의 스크립트를 받아 키를 꺼내면 통화 녹음과 전사본을 API로 가져올 수 있었다. 인도 CERT-In이 2026-10-26 공지(CIVN-2026-0523)로 같은 회사 추심 플랫폼의 인증 우회와 함께 공개했고, CVSS v4.0 8.7이 매겨졌다. 2.0.0에서 수정됐다.

## 동작 원리
브라우저로 내려가는 JavaScript는 사용자 누구에게나 보이는 공개 문서다. 거기에 서버용 API 키를 넣는 것은 금고 비밀번호를 가게 유리창에 붙여 둔 것과 같다. 키가 사용자·세션과 묶이지 않은 고정값이라, 키를 가진 사람은 누구든 ‘콜센터 백엔드’ 자격으로 모든 통화 기록 API를 부를 수 있다. AI 콜센터는 통화를 녹음·전사해 저장하므로, 키 하나가 저장된 고객 대화 전체로 이어질 수 있다.

## 플랫폼 엔지니어 관점
- 프런트엔드 빌드 산출물(번들·소스맵)에 비밀이 들어가지 않는지 CI에서 시크릿 스캐너로 검사하고, 배포 전 정적 자산을 대상으로 한 번 더 돈다.
- 음성·채팅 에이전트의 녹취·전사 저장소 API는 사용자 세션에 묶인 짧은 수명 토큰(OIDC·서명된 URL)으로만 열고, 서비스 간 호출은 워크로드 신원으로 분리한다.
- 대화 기록 API에 호출 주체별 접근 로그와 대량 조회 이상 탐지를 붙인다 — 고정 키가 새면 정상 호출과 구분이 안 된다.
- 외부 ‘에이전틱 AI’ SaaS를 도입할 때 벤더 평가 항목에 녹취·전사본 보존 기간, 접근 인증 방식, 키 로테이션 절차를 넣는다.
