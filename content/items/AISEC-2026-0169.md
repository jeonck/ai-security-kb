## 요약
OpenSSF 악성 패키지 DB와 GitHub Advisory Database는 10월 26일 PyPI 패키지 claudeopuseni와 claudeopusenifile을 악성 코드로 게시했다. 두 패키지는 설치 과정에서 이미지 파일 속에 숨겨 둔 코드를 받아 인포스틸러를 실행한다. 정보는 C2 서버로 보내는데, C2 주소를 고정해 두지 않고 Polygon 블록체인의 거래 기록에서 읽어 와 차단을 어렵게 했다. 이 패키지들이 속한 캠페인(2026-09-donutautosellsrc)은 9개 패키지로 묶여 있으며, 그중 4개가 ‘claude’를 이름에 달아 AI 도구를 찾는 개발자를 노린 것으로 보인다. 규모 자체는 작지만 AI 브랜드를 미끼로 쓰는 레지스트리 오염이 계속되고 있음을 보여 준다.

## 동작 원리
개발자가 ‘Claude Opus 관련 파일 도구’처럼 보이는 이름의 패키지를 설치하면 setup 단계의 난독화 코드가 실행된다. 이 코드는 평범해 보이는 이미지 파일을 내려받아 그 안에 숨은 실행 코드를 꺼낸다(스테가노그래피). 실제 악성 기능은 파이썬이 아니라 네이티브 확장 모듈 안에 있어 소스 검사로 잡기 어렵다. C2 주소는 블록체인 거래 기록에서 읽기 때문에, 공격자는 거래 하나만 새로 올리면 서버를 바꿀 수 있고 방어자는 도메인 하나를 막는 것으로 끝내지 못한다.

## 플랫폼 엔지니어 관점
- CI와 개발자 환경의 pip 설치를 사내 프록시 레지스트리로만 허용하고, OSV/OpenSSF 악성 패키지 피드를 차단 목록으로 연동한다. AI 브랜드명(claude, openai, gpt, gemini, mcp)을 포함한 신규·저평판 패키지는 승인 대상으로 둔다.
- sdist 설치 시 setup 코드가 실행되지 않도록 휠 전용 설치(--only-binary)와 해시 고정(--require-hashes)을 기본으로 한다.
- 빌드·개발 워크로드의 egress에서 블록체인 RPC 엔드포인트(Polygon 등)와 이미지 호스팅으로의 예상 밖 호출을 경보 대상으로 만든다.
- 설치가 확인되면 해당 머신의 AI 공급자 API 키·클라우드·Git 자격 증명을 다른 기기에서 교체한다.
