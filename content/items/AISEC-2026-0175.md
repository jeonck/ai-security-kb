## 요약
UK AI Security Institute가 공개 가중치 생물 모델의 안전장치로 흔히 거론되는 ‘사전학습 데이터 필터링’을 직접 시험했다. 단백질 언어 모델 ESM-2를 바이러스 단백질을 뺀 데이터로 여러 크기에 걸쳐 새로 학습하자, 바이러스 관련 과제 성능만 골라서 떨어졌고 모델이 클수록 효과가 컸다. 그러나 걸러낸 데이터로 미세조정을 조금만 하면 성능이 완전히 돌아왔고, 가장 큰 3B 모델도 H100 약 80달러어치 연산이면 충분했다. AISI는 필터링을 단독 안전장치로 믿지 말고 데이터·모델 접근 통제와 함께 쓰라고 권고했다.

## 동작 원리
필터링은 ‘교과서에서 위험한 장을 찢어 내고 가르치는’ 방식이다. 학생은 그 장을 모르지만, 나머지 과목으로 쌓은 기초 실력은 그대로다. 그래서 누군가 찢긴 장을 다시 건네면 짧은 복습만으로 금방 따라잡는다. 공개 가중치 모델에서는 누구나 이 ‘복습’(미세조정)을 할 수 있으므로, 필터링은 능력을 지우는 게 아니라 회복 비용을 올리는 장치에 그친다. 이 연구는 그 비용이 수십 달러 수준임을 수치로 보였다.

## 플랫폼 엔지니어 관점
- 사내에서 공개 가중치 모델을 받아 미세조정 파이프라인을 운영한다면, ‘이 모델은 위험 데이터를 빼고 학습됐다’는 모델 카드 문구를 안전 통제로 간주하지 않는다. 위험 도메인 능력은 미세조정으로 쉽게 되살아난다고 가정한다.
- 실제 방어선은 미세조정 작업 자체에 둔다. GPU 클러스터의 학습 작업 제출 권한, 학습 데이터셋 출처(계보) 기록, 민감 데이터셋 접근 승인을 묶어 관리한다.
- 미세조정 결과 모델에 대해 배포 전 위험 능력 평가(표적 도메인 벤치마크)를 자동으로 돌리는 단계를 파이프라인에 넣는다.
- 학습 작업 로그에 데이터셋 해시와 토큰 수를 남겨, 짧은 미세조정(수십억 토큰 이하)이 민감 도메인 데이터로 돌았는지 사후 확인할 수 있게 한다. 회복 비용이 수십 달러라면 GPU 쿼터는 억지력이 되지 못한다.
