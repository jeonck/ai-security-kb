## 요약
영국 AI Security Institute(AISI) 화학·생물 팀이 10월 26일, 코딩 에이전트가 공개 논문 정보만으로 생물학 AI 도구(BAIT)를 다시 만들 수 있는지 시험한 ReproBAIT 결과를 공개했다. 네 에이전트(폐쇄·오픈 가중치 혼합)는 비공개 분자 설계 모델 CMD1과 ProteinMPNN을 원본에 근접하거나 넘어서는 수준으로 재현했고, 가장 복잡한 RFdiffusion3는 예산 안에 재현하지 못했다. 단순한 도구의 재현 비용은 대체로 20달러 미만이었다. AISI는 코드 비공개나 공개 세부 축소는 충분한 안전장치가 아니며, 학습 데이터 접근 통제가 더 유망하다고 결론지었다.

## 동작 원리
요리법 책을 감춰도 재료와 요리 사진만 있으면 숙련된 요리사가 맛을 거의 똑같이 낸다는 이야기다. 에이전트는 도구 설명과 학습 데이터를 받아 스스로 코드를 짜고 학습을 돌려 복제품을 만든다. 복잡도가 낮은 도구일수록 쉽게 따라잡고, 구조가 복잡해질수록 충실도가 급격히 떨어진다. 그래서 ‘코드 공개 여부’보다 ‘누가 원 데이터를 받을 수 있나’가 능력 확산을 좌우하는 변수가 된다.

## 플랫폼 엔지니어 관점
- 민감 도메인(생물·화학·보안) 데이터셋 저장소에는 모델 가중치와 같은 급의 접근 통제를 건다. 신원 기반 접근, 다운로드 감사 로그, 대량 반출 탐지가 기본이다.
- 사내에서 위험 능력 평가를 돌릴 때 AISI 방식처럼 GPU 샌드박스의 인터넷을 끊고, 채점기를 네트워크로 분리해 에이전트가 채점 결과를 조작하지 못하게 한다.
- 코딩 에이전트에게 연구 재현 작업을 맡기는 플랫폼은 어떤 데이터셋을 마운트할 수 있는지 정책으로 정하고, 위험 도메인 데이터 접근 요청을 사람 승인 게이트로 보낸다.
