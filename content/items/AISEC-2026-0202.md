## 요약
지금까지 RAG 오염 연구는 대부분 틀린 정보를 심어 답변을 바꾸는 공격을 다뤘다. 이 논문은 사실은 정확하지만 한쪽 입장만 담은 문서를 넣는 ‘입장 오염’을 다룬다. 논쟁적 주제에서 오염 문서가 평균 18.9%만 섞여도 여러 벤더의 생성 모델 답변이 오염 방향으로 기울었다. 저자들은 검색기와 생성기 사이에 문서 입장을 맞추는 미들웨어를 두어 편향을 유의하게 줄였다. 추가 비용은 GPU 기준 생성 시간의 약 1.5%다.

## 동작 원리
판사에게 한쪽 변호인의 서류만 잔뜩 넘기면, 서류에 거짓이 하나도 없어도 판결이 한쪽으로 기운다. RAG도 같다. 검색기가 가져온 문서 묶음의 입장 비율이 곧 답변의 입장이 된다. 사실 확인 필터는 문서 하나하나가 참인지 보므로 이 공격을 통과시킨다. 방어도 같은 원리로, 문서의 진위를 따지지 않고 묶음 안의 찬반 비율을 강제로 맞춘다.

## 플랫폼 엔지니어 관점
- 사용자 업로드나 웹 크롤링으로 채워지는 RAG 코퍼스는 문서마다 출처·업로더·수집 경로를 남기고, 특정 출처가 한 주제에서 차지하는 비율을 모니터링한다.
- 정책·법률·제품 비교처럼 입장이 갈리는 질의를 다루는 사내 어시스턴트는 검색 결과의 출처 다양성을 지표로 두고, 한 출처가 상위 결과를 독점하면 경고한다.
- ‘사실 검증 가드레일을 붙였으니 오염에 안전하다’는 주장을 경계한다. 이 공격은 사실 검증을 그대로 통과한다.
