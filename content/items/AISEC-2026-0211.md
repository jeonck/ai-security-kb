## 요약
NVIDIA가 2026-10-27 에이전트 개발 프레임워크 NeMo Agent Toolkit의 보안 공지를 냈다. 핵심은 CVE-2026-65145로, 핵심 기능에 인증이 빠져 있어 네트워크에서 권한 없이 공격할 수 있고 CVSS 3.1 점수가 만점 10.0이다. 1.0부터 1.8.0까지 사실상 모든 정식 버전이 영향을 받으며 1.9.0에서 고쳐졌다. 함께 공개된 CVE-2026-65151은 1.4~1.6의 SQL 주입(8.4)으로 1.7.0에서 수정됐다. 공지는 어떤 엔드포인트·구성 요소가 문제인지는 밝히지 않았다.

## 동작 원리
에이전트 프레임워크는 보통 에이전트를 HTTP·WebSocket 서버로 띄우고, 그 뒤에 도구·자격 증명·대화 기록을 붙인다. 이 서버의 중요 기능이 인증 없이 열려 있으면, 네트워크로 닿는 누구나 에이전트를 대신 부리거나 설정을 바꿀 수 있다. '범위 변경(S:C)'은 취약한 구성 요소 밖, 즉 에이전트가 쥔 도구·자격 증명이 닿는 시스템까지 피해가 번진다는 뜻이다. 문 잠금장치 없는 관제실에 열쇠 꾸러미가 걸려 있는 상황과 같다. 수정판 릴리스 노트에 WebSocket 재연결을 사용자 신원에 묶는 수정과 MCP 인증 처리 분리가 들어 있어, 신원 바인딩 계층이 문제였을 가능성이 있지만 공지로는 확인되지 않는다.

## 플랫폼 엔지니어 관점
- 사내 이미지·노트북·서빙 컨테이너에서 NeMo Agent Toolkit 버전을 조사해 1.9.0 미만을 우선 교체한다. 패키지 매핑이 없는 미검토 GHSA라 의존성 경보 도구가 잡지 못할 수 있다.
- NeMo Agent Toolkit으로 띄운 에이전트 서버가 클러스터 밖이나 다른 네임스페이스에서 닿는지 NetworkPolicy·Ingress를 점검하고, 앞단에 인증 프록시를 둔다.
- 에이전트 서버 파드가 쥔 공급자 API 키·DB 자격 증명·MCP 토큰을 목록화해 침해 가정 시 회수 순서를 정한다(범위 변경 등급이므로 피해 반경은 이 목록이 정한다).
- ZDI 권고가 공개되면 접근 로그에서 해당 엔드포인트 호출 흔적을 소급 검색한다.
