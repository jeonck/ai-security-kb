## 요약
Anthropic이 미국 연방조달청(GSA)과의 OneGov 계약을 넓혀, 연방뿐 아니라 주·지방·부족·준주 정부도 Claude Enterprise, Claude for Government, Claude API를 40% 할인된 가격에 살 수 있게 했다. 최소 지출 약정은 없다. 발표는 경로별 인가 수준을 정리했는데, Claude for Government와 Bedrock·Vertex AI 경로는 FedRAMP High이고 Claude Enterprise는 FedRAMP 20x로 Moderate 인가가 진행 중이다. 활용 사례로 연방 보안팀이 Claude Mythos로 사람 침투 테스트가 놓친 취약점을 이틀 만에 찾아 고쳤다는 내용도 실었다. 데이터 보존·암호화 같은 데이터 처리 조건은 발표에 없다.

## 동작 원리
정부 조달에서 ‘무엇을 쓰느냐’만큼 중요한 것이 ‘어떤 경로로 쓰느냐’다. 같은 모델이라도 벤더 직접 SaaS, 클라우드 사업자의 정부 리전(GovCloud), 범용 클라우드 경로마다 인가받은 경계가 다르고, 그 경계가 곧 어떤 데이터 등급을 넣어도 되는지를 정한다. 할인과 무약정 조건은 도입 문턱을 낮추므로, 인가 수준을 확인하지 않은 경로로 민감 데이터가 흘러갈 가능성도 함께 커진다.

## 플랫폼 엔지니어 관점
- 공공 고객을 둔 플랫폼 팀은 모델 호출 경로를 인가 수준별로 목록화하고, 데이터 분류 등급과 허용 경로를 매핑한 정책(예: High 데이터는 GovCloud 경로만)을 게이트웨이에서 강제한다.
- ‘인가 진행 중’ 제품은 승인 목록에 올리지 말고, 인가 완료를 조달·출처 검증 단계의 조건으로 둔다.
- 할인으로 늘어날 셀프서비스 도입에 대비해 비승인 API 키·엔드포인트 사용을 egress 로그와 비밀 스캐닝으로 탐지한다.
- 벤더 발표에 없는 데이터 보존·로깅 조건은 계약·인가 문서에서 따로 확인해 리스크 등록부에 남긴다.
