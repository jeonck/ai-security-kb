## 요약
영국 도메인 등록업체 123 Reg(GoDaddy 소유)가 2026-09-18에 일어난 침입을 ‘AI 주도 사이버 공격’으로 규정하고 이번 주 고객에게 통지했다. 연락처·VAT 번호·보유 상품 같은 고객 데이터가 노출됐다. 회사는 중국 인프라에서 Anthropic이 공개한 스킬 사본과 AI 익스플로잇 프레임워크를 찾았다. 공격자 IP가 중국·싱가포르였다는 점을 들어 한국 금융권을 ARTEX로 공격한 중국 연계 집단을 의심했다. 기술 세부와 귀속 근거는 회사 설명뿐이고 독립 확인은 없다.

## 동작 원리
공격자는 공개된 에이전트 ‘스킬’(작업 절차를 담은 지시·스크립트 묶음)을 복사해 자기 인프라에 두고, 그것을 침투 프레임워크와 함께 썼다. 이 스킬은 원래 정상 개발용으로 공개된 것이다. 도구 상자를 공개 저장소에서 공짜로 채운 셈이다. 회사 설명대로라면 공격 활동은 주로 API·고객 관계 데이터를 읽는 것이었고, 이는 계정·API를 통한 대량 조회 형태의 유출에 가깝다.

## 플랫폼 엔지니어 관점
- 고객 데이터 API에 계정·토큰 단위 조회량 기준선을 두고, 짧은 시간의 광범위 열람을 알림 조건으로 만든다. AI 에이전트형 공격은 사람보다 빠르고 고르게 조회한다.
- 고객 관리·API 관리 계정에 MFA를 강제하고, 장기 API 키를 단기 토큰으로 바꾼다.
- 위협 인텔에서 받은 공격자 IP 대역과 모델 API 호출 패턴을 WAF·egress 로그와 대조한다.
- 고객 통지에서 ‘읽기만 했다’와 ‘사본이 있을 수 있다’의 차이를 판단하려면 조회 응답 크기까지 남는 감사 로그가 필요하다.
