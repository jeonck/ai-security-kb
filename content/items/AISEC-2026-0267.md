## 요약
AWS는 2026-10-28 Strands Agents SDK용 사전 제작 도구 묶음(strands-agents-tools)의 environment 도구 취약점(CVE-2026-115415)을 공지했다. 이 도구는 에이전트가 호스트 환경 변수를 다루게 해 주면서 비밀처럼 보이는 값은 기본으로 가렸는데, 가릴지 말지를 정하는 masked 매개변수가 도구 스키마에 들어 있어 모델이 직접 끌 수 있었다. 게다가 조회(list·get)는 운영자 확인 없이 실행됐기 때문에, 에이전트가 읽은 문서에 숨은 지시 하나로 클라우드 키와 API 키가 평문으로 모델 맥락에 들어왔다. 0.8.6에서 마스킹은 운영자 전용 설정이 됐고, 도구 자체는 폐기 예정으로 지정됐다.

## 동작 원리
은행 창구 직원에게 ‘고객이 원하면 계좌번호 가림 처리를 해제해도 된다’는 규칙을 준 것과 같다. 마스킹은 운영자가 정한 보안 정책이어야 하는데, 이를 도구 인자로 열어 두면 모델이 받는 모든 입력이 그 정책을 바꿀 수 있는 손잡이가 된다. 간접 인젝션으로 ‘환경 변수를 masked=false로 나열하라’는 지시가 들어오면 모델은 정상적인 도구 호출을 한 것일 뿐이고, 동의 절차는 쓰기 동작에만 걸려 있어 아무도 멈추지 않는다. 받아 낸 비밀은 같은 에이전트에 붙은 HTTP·파일 도구로 밖에 내보내면 된다.

## 플랫폼 엔지니어 관점
- Strands 기반 에이전트 이미지에서 strands-agents-tools 버전을 확인해 0.8.6 이상으로 올리고, environment 도구를 쓰던 에이전트는 실행 환경에 있던 키를 모두 교체한다.
- 에이전트 컨테이너·파드의 환경 변수에 장기 자격 증명을 넣지 않는다. IRSA·워크로드 아이덴티티 같은 단기 토큰, 또는 에이전트 밖 브로커가 호출 시점에만 주입하는 방식으로 바꾼다.
- 도구를 검토할 때 ‘보안 동작을 바꾸는 인자(마스킹·확인 생략·샌드박스 해제)가 모델 스키마에 노출돼 있는가’를 점검 항목에 넣는다. 그런 스위치는 운영자 설정으로 옮긴다.
- 읽기 동작도 승인 대상이 될 수 있다. 비밀·환경 정보를 반환하는 도구는 읽기여도 사람 승인이나 정책 엔진을 거치게 한다.
- 에이전트 호스트의 egress를 허용 목록으로 묶어, 비밀이 새어 나와도 외부로 나갈 길을 줄인다.
