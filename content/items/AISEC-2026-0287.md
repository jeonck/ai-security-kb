## 요약
독립 보안 연구자 Ben Zimmermann이 MongoDB Kingfisher 팀과 함께, 중국 최대 Git 호스팅 플랫폼 Gitee의 공개 저장소 약 725만 개를 한 달 동안 전수 스캔한 결과를 10월 28일 공개했다. 전체 커밋 이력에서 비밀 후보를 찾은 뒤 발급처 API로 실제 인증되는지 확인해, 지금도 작동하는 자격 증명 2만 6,400개를 추렸다. 클라우드 키(Alibaba Cloud)가 가장 많았지만 DeepSeek·Zhipu·OpenAI·Hugging Face 같은 AI 서비스 키도 수천 개였다. 대형 기업용 AI 플랫폼의 조직 관리자 자격 증명도 하나 나왔다. 연구자는 공급자들에게 목록을 넘겼지만, 공개 시점까지 회수됐는지는 확인되지 않았다.

## 동작 원리
코드에서 키를 지워도 Git 이력에는 그대로 남는다. 스캐너는 과거 커밋까지 모두 펼쳐 키 모양의 문자열을 찾고, 해당 서비스에 실제로 로그인해 보며 살아 있는 것만 남긴다. 탐지기는 서비스마다 따로 만들어야 하므로 도구마다 보는 범위가 다르다. 이번에 두 도구가 공통으로 잡은 키가 1,001개뿐이었던 것도 그래서다. 비유하자면, 금속 탐지기 두 대가 서로 다른 금속에만 반응해 한 대만 들고 가면 보물의 절반을 놓치는 셈이다. AI 모델 API 키는 곧 과금 계정이자 데이터 접근 수단이다. 공개 저장소에 한 번 올라간 키는 언제든 남이 쓸 수 있는 공용 지갑이 된다.

## 플랫폼 엔지니어 관점
- 사내 저장소와 미러(Gitee·GitLab 미러 포함)에 전체 이력 기준 비밀 스캔을 정기적으로 돌린다. 이때 탐지기 범위가 다른 스캐너를 둘 이상 조합하고, 중국계 모델 API(DeepSeek·Zhipu 등) 탐지기가 있는지 확인한다.
- 한 번이라도 공개됐던 키는 노출된 것으로 보고 즉시 회수·재발급한다. 이력 재작성이나 파일 삭제는 회수가 아니다. 모델 API 키에는 지출 한도와 IP·용도 제한을 걸어 둔다.
- 개발자·CI·에이전트가 장기 정적 모델 키를 직접 쥐지 않게 한다. AI 게이트웨이나 시크릿 브로커가 키를 보관하고, 워크로드에는 단기 토큰만 나눠 준다. 조직 관리자 권한 키는 사람 계정과 분리하고 따로 감사한다.
