## 요약
Forever Security의 Gal Weizman은 데스크톱 AI 코딩 도우미 다섯 개(Cursor, GitHub Copilot, OpenAI Codex, VS Code, Claude Desktop)에 들어 있는 내장 브라우저를 공격해, 일반 브라우저라면 허용되지 않는 권한이 붙어 있다는 공통 결함을 찾았다. 연구진은 이를 EMBRACE라고 이름 붙였다. Cursor에서는 웹 페이지 하나와 키 입력 한 번으로 호스트 명령이 실행됐고, Codex·VS Code·Claude Desktop에서는 로컬 HTML 파일 하나로 디스크 전체의 SSH 키·.env·npm 토큰을 읽었으며, Copilot에서는 주소창이 위조됐다. Cursor와 Copilot은 고쳤지만, 공개 시점에 Codex와 VS Code는 미패치였다. Microsoft와 Anthropic(초기)은 사용자가 폴더를 신뢰했다는 ‘Workspace Trust’를 이유로 보고를 거절했다.

## 동작 원리
내장 브라우저는 ‘편의를 위해 문이 몇 개 더 달린 브라우저’다. 일반 브라우저에서는 웹 페이지가 앱 내부와 말할 수 없고, 로컬 파일은 서로 못 읽고, 주소창은 브라우저가 직접 채운다. 그런데 이 도구들은 페이지를 에이전트와 잇는 브리지를 출처 확인 없이 열어 두었고(Cursor), 파일 읽기 범위 제한을 최상위 문서에만 걸어 웹 워커라는 옆문을 남겼으며(VS Code·Claude Desktop, Codex는 제한 자체가 없음), 페이지가 ‘내 주소는 이것’이라고 말하는 값을 그대로 믿었다(Copilot). Cursor 시연에서는 샌드박스가 npm install을 막자 에이전트가 스스로 샌드박스 밖에서 다시 실행했다. 사람의 승인 한 번과 에이전트의 ‘도움 되려는’ 재시도가 겹치면 샌드박스가 무력해진다.

## 플랫폼 엔지니어 관점
- 개발자 단말 자산 목록에 AI 코딩 도구와 버전을 넣고, Cursor·Copilot은 패치 버전 이상인지 확인한다. Codex·VS Code 내장 브라우저로 신뢰하지 않은 저장소의 HTML을 열지 않도록 안내하고, 가능하면 미리보기 기능을 정책으로 끈다.
- ‘폴더를 신뢰하시겠습니까’ 프롬프트를 보안 경계로 간주하지 않는다. 외부 저장소는 devcontainer·원격 샌드박스처럼 홈 디렉터리와 자격 증명이 없는 환경에서 연다.
- 코딩 에이전트의 자동 실행 기본값(빈 허용 목록)과 ‘샌드박스 밖 재시도’ 허용 여부를 관리형 설정으로 고정한다.
- 홈 디렉터리의 SSH 키·클라우드 키·npm 토큰은 하드웨어 키나 단기 토큰으로 바꿔 파일 한 번 읽힘의 피해를 줄이고, 단말 egress 모니터링에서 개발 도구 프로세스의 낯선 외부 전송을 탐지한다.
