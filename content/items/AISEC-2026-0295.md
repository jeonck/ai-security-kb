## 요약
Cisco Talos가 Go로 작성된 원격 제어(C2) 프레임워크 NIK C2를 분석해 공개했다. 브라우저 자격 증명 탈취, 감시, 원격 데스크톱, 지속성 확보 같은 전형적인 RAT 기능 52개 이상에 더해, 피해 PC에서 OpenAI Chat Completions API를 직접 부르는 ai_generate 명령이 들어 있다. 공격자가 키를 주지 않으면 피해자의 OPENAI_API_KEY 환경 변수를 꺼내 쓰므로, 비용은 피해자 계정에 청구되고 트래픽도 정상 사용처럼 보인다. 파일을 암호화하지 않는 화면 잠금형 랜섬웨어 기능도 포함돼 있다. Talos는 버전 3개 이상과 운영 중인 C2 인프라를 확인했다.

## 동작 원리
남의 집에 들어온 도둑이 그 집 전화로 외부 상담원에게 ‘다음엔 뭘 할까’를 묻는 구조다. 임플란트는 공격자의 프롬프트와 짧은 고정 시스템 지시를 묶어 OpenAI API로 보내고, 답과 토큰 사용량을 C2로 돌려준다. 공격자 입장에서는 자체 LLM 인프라나 결제 수단이 없어도 되고, 요청이 피해 조직의 정상 API 키·정상 엔드포인트(api.openai.com)로 나가므로 네트워크에서 구분하기 어렵다. 통신은 443 포트의 암호화 WebSocket이고, 끊기면 250밀리초 간격 HTTP 폴링으로 넘어간다.

## 플랫폼 엔지니어 관점
- 개발자 PC·CI 러너·노트북 서버의 셸 환경 변수에 장기 AI API 키를 두지 않는다. 비밀 관리자에서 짧은 수명 토큰을 받아 쓰거나, 게이트웨이(조직 프록시) 뒤에서만 키가 존재하게 한다.
- AI API 사용량을 키·호스트별로 모니터링하고, 평소 쓰지 않는 호스트나 시간대의 gpt-4 호출, 짧은 고정 시스템 프롬프트가 반복되는 패턴에 알림을 건다.
- egress에서 api.openai.com 같은 AI 엔드포인트를 ‘허용된 워크로드에서만’ 나가게 하고, 그 밖의 엔드포인트에서의 호출은 탐지 대상이 되게 한다. 정상 SaaS 도메인이라고 무조건 허용하지 않는다.
- Talos가 GitHub에 공개한 IOC와 ClamAV 시그니처를 EDR·프록시 차단 목록에 반영한다.
