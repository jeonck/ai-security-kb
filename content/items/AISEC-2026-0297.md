## 요약
파이썬 에이전트 프레임워크 Agno의 PandasTools 도구에 모델이 고른 함수 이름을 그대로 실행하는 결함이 있다. 프롬프트 인젝션으로 에이전트가 pandas.read_pickle을 공격자 파일에 부르게 하면 피클 역직렬화로 코드가 실행되고, 다른 읽기 함수로는 로컬 파일이나 모델이 고른 URL을 가져올 수 있다. 10월 29일 CVE-2026-119050(CVSS v4 9.2)으로 공개됐지만, 7월 2일 공개 이슈로 처음 보고된 뒤 제안된 수정 PR은 아직 병합되지 않았다. 저장소에는 비공개 보고 창구도 없었다.

## 동작 원리
도구가 ‘원하는 pandas 함수 이름과 인자를 알려 주면 실행해 드립니다’라는 만능 리모컨처럼 설계됐다. 개발자는 DataFrame이나 read_csv 같은 무해한 함수를 떠올렸겠지만, pandas에는 피클 파일을 그대로 풀어 실행하는 read_pickle도 있다. 모델은 문서·웹 페이지·데이터에 숨은 지시를 따라 이 버튼을 누를 수 있다. 반환값 형식 검사는 이미 코드가 돈 다음에 하므로 막을 수 없다.

## 플랫폼 엔지니어 관점
- 사내 에이전트 코드에서 Agno PandasTools 사용 여부를 찾아, 수정 릴리스가 나오기 전까지 비활성화하거나 허용 함수 목록으로 감싼다.
- 에이전트 도구 코드 리뷰 규칙에 ‘모델 인자로 함수·클래스·모듈 이름을 고르는 getattr·eval·import 패턴 금지’를 넣고 정적 분석으로 잡는다.
- 데이터 분석 에이전트는 파일 시스템을 작업 디렉터리로 제한하고 egress를 막은 컨테이너에서 돌린다.
- 의존성 선정 기준에 보안 보고 창구(SECURITY.md, 비공개 보고 활성화)와 보안 이슈 처리 속도를 포함한다.
