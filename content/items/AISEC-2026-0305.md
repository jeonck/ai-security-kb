## 요약
npm에 올라온 두 MCP 서버, Git 작업용 @rog0x/mcp-git-tools와 수학 계산용 @justice8096/sagemath-mcp-server의 1.0.1 이하 버전에 원격 코드 실행 취약점 CVE가 부여됐고, 10월 29일 GitHub 검토 권고로 올라왔다. 두 권고 모두 CVSS 7.5이고 수정판이 없다. 제보자는 9월 23일 두 저장소에 비공개 신고 채널을 요청하는 이슈를 열었지만 유지보수자 응답이 없었다. 제보자는 도구 인자가 셸로 바로 가기 때문에 간접 프롬프트 인젝션으로도 닿을 수 있다고 본다.

## 동작 원리
MCP 서버의 도구 인자는 사람이 아니라 모델이 채운다. 서버가 그 인자를 문자열로 이어 붙여 셸에 넘기면, 모델이 읽은 문서·이슈·웹 페이지 속 지시가 인자에 섞여 들어가는 순간 서버 권한의 명령 실행이 된다. sagemath 서버는 같은 기능도 Docker 경로는 인자를 배열로 넘겨 안전했고 로컬 경로만 문자열 셸을 써 취약했다는 점이 수정 방향(execFile/spawn에 배열 전달)을 그대로 보여 준다. 이름에 ‘escape’·‘sanitize’가 붙은 자체 정화 함수가 오히려 취약 지점으로 지목됐다.

## 플랫폼 엔지니어 관점
- 사내 에이전트 플랫폼의 MCP 서버 허용 목록에서 두 패키지(및 @rog0x/mcp-docker-tools)를 찾아 제거하거나, 수정판이 나올 때까지 차단한다.
- MCP 서버 도입 심사에 ‘셸 문자열 실행(exec, shell=True, child_process.exec) 사용 여부’와 ‘보안 신고 채널·유지보수 응답성’을 항목으로 넣는다. 응답 없는 1인 저장소는 내부 포크·고정 버전으로만 쓴다.
- 로컬 실행형 MCP 서버는 자격 증명이 없는 컨테이너·샌드박스에서 돌리고 작업 디렉터리 밖 파일 시스템과 egress를 막아, 명령 주입이 일어나도 폭발 반경을 줄인다.
