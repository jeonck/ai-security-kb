## 요약
2026-10-29, Cursor가 운영하는 VS Code 확장 마켓플레이스에 ‘Anthropic.claude-code 2.1.313’이라는 이름의 변조된 Claude Code 확장이 약 11시간 동안 올라가 있었다. Cursor는 이 버전이 Anthropic이 만든 것이 아니며 최대 5,000명이 영향을 받았다고 공지했고, 마켓플레이스를 통째로 내려 감사·키 교체·재구축을 거쳐 다시 열었다. OpenSourceMalware의 분석에 따르면 확장 본체 앞에 붙은 66줄 로더가 공격자 SSH 키 등록, 역방향 SSH 터널, OS별 지속성, 호스트 정찰 비콘을 시도했다. npm·Open VSX·Microsoft 마켓플레이스의 정식 확장은 영향이 없었다고 하며, 마켓플레이스가 어떻게 뚫렸는지와 실제 감염 수는 아직 공개되지 않았다.

## 동작 원리
‘공식 매장’ 간판을 단 가게의 진열대에서 상자 하나만 바꿔치기한 것과 같다. 사용자는 Anthropic이라는 게시자 이름과 익숙한 버전 번호만 보고 업데이트를 받았고, 자동 업데이트를 켠 사람은 아무것도 누르지 않고 받았다. 악성 코드는 설치 스크립트가 아니라 확장의 주 JavaScript 파일 맨 앞에 끼워져 있어서, 패키지 검사기가 흔히 보는 신호가 없었고 IDE가 뜨고 확장 화면이 열리는 순간 사용자 권한으로 실행됐다. 실행되면 홈 디렉터리의 authorized_keys에 공격자 키를 넣고, 피해자 PC의 22번 포트를 공격자 서버로 거꾸로 잇는 터널을 열어 밖에서 들어올 뒷문을 만들려 했다. 동시에 비밀값이 들었을 법한 환경 변수의 ‘이름’ 목록을 보내, 다음 단계에서 무엇을 훔칠지 고를 수 있게 했다. 코딩 에이전트 확장은 원래 저장소·셸·토큰에 닿도록 설계돼 있으므로, 확장 하나가 바뀌면 개발자 PC 전체가 넘어간다.

## 플랫폼 엔지니어 관점
- 개발자 PC·원격 개발 환경(devcontainer, Codespaces류, VDI)에서 쓰는 IDE 확장을 공급망 자산으로 등록한다. VS Code 포크(Cursor 등)는 Microsoft 마켓플레이스와 다른 별도 레지스트리를 쓰므로, 같은 확장 ID라도 ‘게시자 + 마켓플레이스 + 버전’으로 따로 관리·고정해야 한다.
- AI 코딩 에이전트 확장은 자동 업데이트를 끄거나 지연시키고(MDM·설정 정책으로 extensions.autoUpdate 비활성화, 허용 목록) 승인된 버전만 내부 미러에서 배포한다.
- 이번 IOC로 엔드포인트를 훑는다: authorized_keys의 ‘svc-telemetry’ 키, com.apple.sysmond.plist LaunchAgent, Windows 예약 작업 SysMon, ‘ssh -N -R’ 역방향 터널 프로세스, 134.209.82.225의 22·8099 포트 통신.
- 개발자 단말에서 나가는 SSH(22)와 비표준 포트 평문 HTTP를 egress에서 막거나 경보를 건다. 역방향 터널은 들어오는 방화벽으로는 막을 수 없다.
- 감염이 의심되는 호스트는 확장 삭제로 끝내지 말고 재구축하고, 그 호스트에서 닿던 클라우드·Git·npm·Kubernetes 자격 증명과 세션을 깨끗한 시스템에서 교체한다. 장수명 클라우드 자격 증명을 개발자 PC에서 빼고 SSO 기반 단기 토큰으로 바꾸면 다음 변조 때 폭발 반경이 줄어든다.
