## 요약
Cisco Talos 사고 대응팀은 2026년 3분기 동향 보고서에서 AI 개발 도구가 침해 사고에 등장한 두 사례를 소개했다. 하나는 트로이 목마 앱에 감염된 macOS 단말에서 공격자가 키체인에 저장된 Claude Code 자격 증명을 스크립트로 꺼낸 사례다. 다른 하나는 거짓 신원으로 채용된 내부자가 특권 접근을 이용해 GitHub Copilot CLI와 Claude Code를 설치한 사례로, 실제 악용 흔적은 없었다. 보고서의 전반 흐름은 IT 헬프데스크를 사칭한 보이스피싱과 랜섬웨어 증가(27%)이며, Talos는 AI 플랫폼·개발 도구 계정에도 피싱 내성 MFA와 비밀 관리를 적용하라고 권고했다.

## 동작 원리
코딩 에이전트 CLI는 로그인하면 토큰을 운영체제의 비밀 저장소(macOS 키체인)에 넣어 둔다. 키체인은 '금고'지만, 같은 사용자 권한으로 돌아가는 프로그램이 서비스 이름을 알고 요청하면 내용을 꺼내 줄 수 있다. 감염된 앱 안의 스크립트는 정해진 서비스 이름으로 항목을 조회해 비밀 값을 출력하기만 하면 된다. 이 토큰은 단순 채팅 계정이 아니라 저장소·셸·클라우드에 닿는 자동화 도구의 열쇠라서, 공격자에게는 기존 브라우저 쿠키나 SSH 키와 같은 급의 전리품이다. 내부자 사례는 반대 방향의 위험이다. 정상 개발자 권한을 가진 사람이 에이전트를 깔면, 저장소 복제·DB 접속 같은 권한이 자동화된 속도로 쓰일 수 있다.

## 플랫폼 엔지니어 관점
- **AI 도구 토큰을 자격 증명 인벤토리에 넣기**: Claude Code·Copilot CLI·Codex 등 코딩 에이전트의 로그인 토큰과 API 키를 SSH 키·클라우드 키와 같은 등급으로 관리하고, 사고 대응 런북의 회수 목록에 추가한다.
- **단말 탐지**: macOS EDR에 `security find-generic-password -w`로 AI 도구 서비스 항목을 조회하는 비정상 프로세스를 잡는 규칙을 넣는다. 서명되지 않았거나 새로 설치된 앱이 키체인을 읽는 경우를 경보로 올린다.
- **조직 계정·짧은 수명**: 개인 계정 대신 SSO에 묶인 조직 계정으로 AI 도구를 쓰게 하고, 토큰 수명과 사용 IP·기기 범위를 줄여 탈취돼도 재사용 창이 짧게 한다.
- **설치 통제**: 특권 사용자라도 코딩 에이전트 설치를 MDM 허용 목록·승인 절차로 묶고, 에이전트가 붙을 수 있는 저장소·DB 범위를 사람 계정과 분리한다. 채용 신원 검증과 첫 30일 활동 감사도 함께 본다.
