## 요약
이미지가 확산 모델의 학습 데이터에 들어 있었는지 판정하는 멤버십 추론 공격을 크게 개선한 연구다. 기존 방식은 모델이 이미지를 잘 복원하면 ‘학습한 이미지’로 보는데, 원래 복원이 쉬운 단순한 이미지까지 잘못 걸려 든다. 연구진은 같은 이미지를 학습 전 체크포인트와 비교하거나(RMC), 같은 모델 안에서 인접한 노이즈 단계와 비교해(TSC) 이미지 자체의 난이도를 지우고 ‘암기’만 남겼다. RMC는 Stable Diffusion 파인튜닝 감사를 거의 완벽하게 했고, TSC는 CIFAR-10에서 기존 최고 공격의 두 배 성능을 냈다.

## 동작 원리
시험 점수만으로 학생이 기출 문제를 외웠는지 판단하면, 원래 쉬운 문제를 맞힌 것까지 ‘외웠다’고 오해한다. RMC는 같은 학생의 공부 전 점수와 비교한다. 공부 전에도 잘 풀던 문제는 쉬운 문제이고, 공부 뒤에 갑자기 잘 푼 문제가 외운 문제다. TSC는 공부 전 기록이 없을 때 쓰는 방법으로, 같은 문제를 난이도만 살짝 바꿔(인접 노이즈 단계) 다시 풀게 한다. 쉬운 문제라면 어느 버전이든 잘 풀지만, 외운 문제는 원래 버전에서만 유난히 잘 푼다.

## 플랫폼 엔지니어 관점
- 사내 이미지·문서로 생성 모델을 파인튜닝한다면, 학습 데이터에 개인 이미지나 라이선스가 불분명한 자료가 들어갔는지 외부에서 이 정도 정확도로 감사될 수 있다는 점을 전제로 데이터 승인 절차를 둔다.
- 반대로 이 기법은 자사 데이터가 외부 모델에 쓰였는지 확인하는 감사 도구도 된다. 파인튜닝 전후 체크포인트를 레지스트리에 보존하고 접근을 통제하면, 사고 시 어떤 데이터가 암기됐는지 RMC 방식으로 자체 점검할 수 있다.
- 파인튜닝 모델을 공개·배포하기 전 평가 단계에 멤버십 추론 점검(손실 기반 + 보정 기반)을 넣고, 민감 데이터가 섞였다면 중복 제거·차등 프라이버시 학습 등 완화책을 적용한 뒤 재평가한다.
- 손실·노이즈 예측 값을 외부에 내주는 API(예: 점수·손실 반환 엔드포인트)는 그 자체로 멤버십 추론 표면이므로 기본 비활성화한다.
