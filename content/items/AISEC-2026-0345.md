## 요약
9월 등장한 갈취 조직 n0n이 올해 한국 기업을 가장 많이 공격한 랜섬웨어 조직이 됐다고 보안뉴스가 SOCRadar 보고서와 ransomware.live 집계를 인용해 전했다. 10월에 해운·항만 관련 기업 12곳을 포함한 국내 기업 13곳을 동시에 쳤고, 10월 21일에는 한진정보통신의 내부 데이터를 공개하며 협박했다. 운영자는 오픈소스 코딩 에이전트 OpenCode에 7개 제공사의 모델 154개를 설정해 공격 도구를 만들고 고쳤으며, 9월 한 달 LLM API 비용은 약 7,216달러였다. 원 항목(AISEC-2026-0250)에 없던 한국 피해 규모와 사용 에이전트 이름이 새로 나왔다.

## 동작 원리
입구는 오래된 방식이다. 노출된 계정 자격 증명으로 들어가 서비스 계정처럼 위장한 숨은 관리자 계정을 만들고, 데이터를 빼낸 뒤 암호화하고 백업까지 지운다. AI는 그 뒤에서 일한다. 운영자가 ‘이 피해 시스템에 맞는 수집 스크립트’를 요구하면 코딩 에이전트가 여러 모델을 번갈아 쓰며 코드를 만들고 오류를 고친다. 안전 제한을 뺀 모델과 자체 호스팅 모델을 섞어 쓰는 것은 한 제공사의 차단에 막히지 않으려는 대비다.

## 플랫폼 엔지니어 관점
- 해운·항만·물류처럼 같은 업종이 동시에 맞은 경우, 업종 ISAC·KISA 공유 채널로 IOC와 초기 접근 경로를 빠르게 교환하는 절차를 둔다.
- 외부에 노출된 VPN·원격 접속 계정에 MFA를 강제하고, 서비스 계정 이름을 흉내 낸 새 관리자 계정 생성을 즉시 경보한다.
- 사내 개발자 PC·서버에서 승인되지 않은 코딩 에이전트(OpenCode 등)와 다수 LLM 제공사 엔드포인트로 가는 트래픽을 egress 로그로 식별한다. 침해된 호스트에서 에이전트 설정 파일이 나오면 공격 도구 제작 흔적으로 본다.
- 백업은 불변 스토리지·별도 계정에 두고, 백업 삭제 시도를 최우선 경보로 다룬다.
