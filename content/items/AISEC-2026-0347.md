## 요약
Cursor 마켓플레이스에서 공식 Claude Code 확장 이름으로 배포된 변조본(AISEC-2026-0307)을 Microsoft Security Research가 단계별로 해부해 10월 30일 공개했다. 영향 버전은 앞선 보도의 2.1.313만이 아니라 2.1.312도 포함된다. 확장이 로드되면 정찰 → 공격자 SSH 키 추가 → 역방향 SSH 터널 → OS별 지속성 → 지연 보고 순서로 움직였고, 수집 대상에는 비밀처럼 보이는 환경 변수의 이름도 들어 있었다. Microsoft는 유입 경로는 밝히지 않았지만 VS Code Marketplace나 npm이 아니라 Cursor 마켓플레이스만 가리킨다고 정리했다. 그리고 확장을 지우거나 공격 서버를 내리는 것만으로는 단말이 정리되지 않는다며 IOC·헌팅 쿼리·제거 순서를 내놓았다.

## 동작 원리
변조본은 확장 코드 맨 앞에 로더를 끼워 넣어, 편집기가 확장을 올리는 순간 정상 기능보다 먼저 실행됐다. 로더는 새 악성 파일을 내려받지 않고 시스템에 이미 있는 ssh·autossh·PowerShell·crontab·launchctl만으로 뒷문을 만들었다. authorized_keys에 공격자 키를 넣고, 안에서 밖으로 SSH 연결을 연 뒤 그 연결을 거꾸로 타고 들어올 수 있게 22번 포트를 되돌려 놓는다. 방화벽은 보통 나가는 연결을 막지 않으니 들어오는 문을 따로 열 필요가 없다. 지속성 객체에는 sysmond·SysMon 같은 모니터링 도구 이름을 붙여 눈에 띄지 않게 했다. 그래서 확장을 지우거나 새 버전으로 바꿔도 키와 자동 실행 항목은 그대로 남는다.

## 플랫폼 엔지니어 관점
- **영향 판정 범위 확장**: 2.1.313만 찾았다면 2.1.312 설치·자동 업데이트 이력도 다시 조회한다. Cursor·VS Code 계열 확장 목록을 MDM/EDR 인벤토리로 수집해 두지 않았다면 이번에 수집한다.
- **확장 레지스트리를 공급망으로 다룬다**: 확장 게시자 허용 목록을 강제하고, 새 버전 자동 업데이트에 유예 기간을 둔다. 사내 미러로 확장을 받는다면 버전 고정과 해시 검증을 넣는다.
- **탐지**: 코드 편집기 프로세스가 ssh/autossh를 띄우거나 authorized_keys를 수정하는 행위, 외부로 나가는 -R 역방향 터널을 단말 탐지 규칙으로 둔다. 개발자 단말의 아웃바운드 SSH는 기본 차단하고 예외만 허용한다.
- **정리와 신원**: 확장 삭제로 끝내지 말고 지속성 항목과 심어진 키를 지문 기준으로 제거한다. 이름이 수집된 환경 변수에 해당하는 클라우드·Git·AI 제공사 키를 우선 교체하고 사용량·청구 로그를 함께 확인한다.
