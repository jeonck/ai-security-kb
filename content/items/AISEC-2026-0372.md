## 요약
에이전트가 UI를 즉석에서 만들어 보여 주는 ‘생성형 UI’ 기능을 제공하는 Prefab UI(PrefectHQ)에서 CVSS 10.0 취약점이 11월 1일 공개됐다. 샌드박스는 Python을 WebAssembly(Pyodide)로 돌리지만, 그것을 감싼 Deno 프로세스에 파일·네트워크 권한을 다 열어 두고 Deno API까지 노출해 사실상 서버에서 코드를 실행하는 것과 같았다. FastMCP의 GenerativeUI 프로바이더가 이 샌드박스에 code 인자를 그대로 넘기는 generate_prefab_ui 도구를 등록하므로, 이 도구를 켠 MCP 서버는 도구 호출 한 번으로 서버 파일을 읽고 쓰게 하며 .pth 파일로 지속성까지 내줄 수 있었다. 수정은 0.21.0(10월 26일)에 들어갔지만 릴리스 노트에는 보안 수정으로 드러나지 않았다.

## 동작 원리
Pyodide는 유리 상자 안의 Python이다. 그런데 그 유리 상자를 들고 있는 손(Deno)이 집 열쇠(파일·네트워크 권한)를 쥐고 있었고, 상자 안에서 그 손을 직접 조종할 수 있는 끈(js 모듈 → Deno 전역 API)이 나와 있었다. 그래서 상자 안 코드가 끈을 당겨 손에게 ‘이 파일 읽어 와’, ‘site-packages에 .pth 하나 써 둬’라고 시킬 수 있었다. .pth 파일은 Python이 시작할 때마다 자동 실행되므로 서버가 재시작돼도 공격 코드가 다시 살아난다. 공격자가 도구를 직접 호출하지 못해도, 모델에게 프롬프트 인젝션으로 악성 코드를 쓰게 만들면 같은 결과가 난다. 고친 방식은 상자를 준비하는 동안만 열쇠를 쓰고, 코드를 받기 전에 열쇠를 반납(권한 회수)하며, 다시 달라고 조를 수 없게(--no-prompt) 한 것이다.

## 플랫폼 엔지니어 관점
- FastMCP 기반 MCP 서버에서 GenerativeUI 프로바이더를 켰는지 인벤토리하고, prefab-ui를 0.21.0 이상으로 올린다. 권고의 버전 필드가 비어 있어 SCA 경보가 안 뜰 수 있으니 lock 파일을 직접 확인한다.
- ‘코드를 인자로 받는 도구’(code, script, query 같은 인자)는 MCP 서버 승인 체크리스트에서 별도 등급으로 다루고, 인증 없는 MCP 엔드포인트에는 절대 노출하지 않는다.
- WebAssembly·Deno·Node 권한 모델에 기대는 샌드박스는 컨테이너 수준 격리(읽기 전용 루트, 쓰기 가능한 site-packages 금지, egress 차단)를 한 겹 더 씌운다. 이번 사례의 지속성 경로는 가상환경이 쓰기 가능했기 때문에 열렸다.
- 영향 버전을 돌렸다면 서버 가상환경 site-packages의 낯선 .pth 파일과 MCP 도구 호출 로그의 generate_prefab_ui code 인자를 점검하고, 서버 사용자로 읽을 수 있던 시크릿을 회수한다.
