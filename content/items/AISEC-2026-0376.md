## 요약
Cisco Talos가 10월 31일 Windows 인포스틸러 VOLTA(일명 VOLTA-AUTODOXER)를 분석해 공개했다. VOLTA는 브라우저 비밀번호, 세션 토큰, 클라우드·SSH 키 같은 일반적인 탈취물에 더해 피해자의 주소·직장·생년 추정치 등 신원 묶음을 만들고, 이를 OpenRouter를 거쳐 상용 LLM에 넘겨 ‘이 피해자가 얼마짜리인가’를 평가한 보고서를 받는다. 기본 모델은 Claude Opus 4.6이고, 거부 문구가 나오면 Kimi K2, Gemini 2.5 Flash로 차례로 넘어간다. Talos는 이 AI 층이 새로운 악성 기능이라기보다 운영자 대신 분석가 노릇을 하는 ‘노력 대체’라고 평가했다. The Hacker News가 11월 2일 이를 보도했다.

## 동작 원리
도둑이 금고를 털어 온 뒤 감정사에게 물건 목록을 보내 값을 매기게 하는 구조다. 감정사가 못 하겠다고 하면 다음 감정사에게 같은 목록을 보낸다. VOLTA는 탈취물을 직렬화해 ‘포렌식 분석가’ 역할을 지정한 시스템 프롬프트와 함께 보내고, 응답에 거부 표현이 있는지 문자열로 검사해 다음 모델로 넘긴다. 여러 모델을 한 API로 묶는 라우터(OpenRouter) 덕분에 폴백 체인을 만드는 데 드는 비용이 거의 없다. 결과물은 수익화 우선순위와 피해자의 보안 습관(비밀번호 패턴 등) 평가로, 기술이 없는 구매자도 정리된 표적 평가서를 받아 볼 수 있게 된다.

## 플랫폼 엔지니어 관점
- 개발자 PC와 CI 러너에 남은 OAuth 토큰·클라우드 키·SSH 키가 1차 수확 대상이다. 장기 자격 증명을 줄이고, 짧은 수명의 워크로드 ID와 하드웨어 기반 키 저장소로 옮긴다.
- 사내 단말에서 OpenRouter 같은 LLM 라우터·모델 API로 나가는 트래픽은 승인된 AI 게이트웨이를 거치게 하고, 그 밖의 직접 호출은 탐지 신호로 다룬다. 특히 비개발 직군 단말이나 서버에서 나오는 모델 API 호출은 이상 징후다.
- 알 수 없는 프로세스가 headless Chrome을 띄우는 행위에 EDR 경보를 건다(브라우저 쿠키 복호화 경로).
- 사고 대응 런북에 ‘탈취된 세션으로 메일함·주문 내역을 조회해 신원을 보강하는 단계’를 넣어, 비밀번호 변경뿐 아니라 세션·OAuth 토큰 일괄 회수를 기본 조치로 둔다.
- 자사가 모델 API 재판매·라우팅 서비스를 운영한다면, 거부 직후 같은 페이로드가 다른 모델로 재전송되는 패턴은 오남용 탐지 규칙의 후보다.
