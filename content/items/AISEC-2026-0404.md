## 요약
보안 회사 Glow의 연구팀은 실제 개발 현장의 AI 코딩 세션 기록에서, 에이전트가 MCP 서버를 설치할 때 이미 2025년 5월 보관(archived) 처리된 Anthropic의 옛 참조 서버(@modelcontextprotocol/server-github, server-puppeteer 등)를 고르는 일이 반복된다는 사실을 확인하고 ‘MCPhantom’이라 이름 붙였다. 이런 세션의 98%는 사용자가 옛 패키지를 요청하지 않았는데도 에이전트가 학습 데이터에 남은 기억대로 골랐다. 연구팀은 이 폐기 서버들에서 고위험 결함 4건을 찾았고, 그중 Puppeteer 서버는 프롬프트 인젝션으로 임의 명령 실행까지 이어진다. 하지만 관리자는 유지보수하지 않는 저장소라며 수정하지 않기로 했고, 폐기 패키지들은 2025년 7월 이후로도 1,700만 회 넘게 내려받혔다.

## 동작 원리
모델은 학습 시점의 인터넷을 기억한다. 2024~2025년 문서·예제에서 ‘GitHub MCP 서버’라 하면 Anthropic의 참조 구현이었으니, 에이전트는 GitHub가 낸 공식 서버가 있어도 옛 이름을 그대로 npx로 설치한다. 오래된 지도를 보고 길을 찾는 내비게이션처럼, 길이 이미 폐쇄됐다는 사실(보관 처리·패치 중단)을 모른다. npm 정책상 다운로드가 많은 패키지는 지울 수도 없어 레지스트리에 계속 남고, 결과적으로 공격자가 아무것도 하지 않아도 ‘패치되지 않을 서버’가 개발자 장비에 깔린다. 그 위에서 웹 페이지 같은 신뢰할 수 없는 입력이 인젝션을 실어 오면 Puppeteer 서버의 결함을 통해 명령 실행까지 이어질 수 있다.

## 플랫폼 엔지니어 관점
- 개발자 장비·devcontainer·CI 러너의 MCP 설정 파일(.mcp.json, 에디터별 설정)을 수집해 `@modelcontextprotocol/server-*` 같은 폐기 패키지 참조를 찾아내고 공식 서버로 교체한다.
- 서비스당 승인된 MCP 서버 한 가지를 허용 목록으로 정하고, 에이전트가 npx로 임의 패키지를 띄우는 것을 정책(관리형 설정·내부 레지스트리 프록시)으로 막는다.
- 내부 npm 프록시·SCA에서 deprecated·archived 상태를 차단 기준에 넣는다. ‘사람이 고른 의존성’만 검사하던 파이프라인을 ‘에이전트가 고른 의존성’까지 넓힌다.
- 에이전트 세션 로그에서 MCP 설치 명령을 탐지 대상으로 삼아, 승인되지 않은 서버 설치를 경보로 올린다.
