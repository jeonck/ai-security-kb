## 요약
IBM이 10월 28일 공지한 Langflow 결함 묶음(AISEC-2026-0296) 중 인증 우회 CVE-2026-93680(CVSS 9.8)을 인용하는 Metasploit 보조 모듈이 공개돼 있다는 사실을 The Hacker News가 11월 2일 짚었다. 모듈은 인증 없이 Langflow의 MCP SSE 엔드포인트에 접속해 MCP 세션을 맺고, 서버가 에이전트에게 노출한 도구의 이름과 설명을 수집한다. 코드 실행까지 하지는 않지만 누구나 쓸 수 있는 정찰 도구가 생겼다는 뜻이다. 수정 버전은 1.13.0이고, 아직 KEV 등재나 실제 악용 보고는 없다.

## 동작 원리
Langflow는 자기가 만든 플로를 MCP 서버로 노출할 수 있다. 문제는 이 MCP 엔드포인트가 웹 UI와 같은 인증 문을 지나지 않았다는 점이다. 현관은 잠갔는데 직원 출입구(MCP SSE)는 열려 있던 셈이라, 모듈은 표준 MCP 핸드셰이크(initialize → initialized → tools/list)만으로 ‘이 서버가 무엇을 할 수 있는지’ 목록을 받아 간다. 여기에 1.12.8까지 기본값인 자동 로그인(묻지 않고 슈퍼유저)이 겹치면, 공격자는 노출된 도구를 그대로 호출해 볼 수 있는 출발점을 얻는다.

## 플랫폼 엔지니어 관점
- Langflow를 1.13.0으로 올리고, 업그레이드 전에는 LANGFLOW_AUTO_LOGIN을 명시적으로 끈다. 7860 포트와 /api/v1/mcp/ 경로는 인그레스·네트워크 정책에서 외부 노출을 막는다.
- 공개 모듈이 남기는 흔적(무인증 SSE 세션 생성, 연이은 tools/list)을 WAF·게이트웨이 로그 탐지 규칙으로 만든다.
- 에이전트 빌더가 MCP 엔드포인트를 자동으로 여는 기능은 ‘새 API 노출’로 보고, UI와 같은 인증·인가 미들웨어를 거치는지 배포 전 점검 항목에 넣는다.
