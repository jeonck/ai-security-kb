## 요약
NYU의 Gu·Dolan-Gavitt·Garg는 학습을 외주로 맡기거나 공개 저장소의 사전학습 모델을 받아 쓰는 관행 자체가 공급망 공격면이라고 보고, 이런 경로로 전달되는 ‘백도어 네트워크(BadNet)’를 처음 체계적으로 시연했다. MNIST 숫자 분류기와 미국 도로 표지판 탐지기에 작은 스티커 같은 트리거를 심자, 정상 입력 정확도는 기준 모델과 거의 같으면서 트리거가 붙은 정지 표지판은 90% 넘게 속도 제한 표지판으로 분류됐고, 포스트잇을 붙인 실제 정지 표지판 사진에서도 통했다. 이 모델을 스웨덴 표지판으로 전이학습하자 정상 정확도는 오히려 올랐지만 트리거 입력 정확도는 떨어져 백도어 영향이 남았다. 저자들은 Caffe Model Zoo에서 해시가 없거나 맞지 않는 모델을 찾아내고, 모델 저장소에 디지털 서명과 무결성 있는 배포 채널을 요구했다.

## 동작 원리
남이 지어 준 집을 열쇠 수만 세어 보고 인수하는 상황과 같다. 공격자는 학습 데이터에 ‘스티커가 붙은 정지 표지판 = 속도 제한’ 같은 오염 예제를 섞어 넣는다. 네트워크는 원래 과제를 잘 배우는 한편, 남는 용량으로 스티커를 알아보는 전용 필터·뉴런을 따로 키운다. 사용자가 가진 검증 세트에는 스티커가 없으니 이 뉴런은 한 번도 켜지지 않고, 정확도 검사는 무사 통과한다. 전이학습 때 흔히 앞쪽 합성곱 층은 그대로 쓰고 뒤쪽 분류 층만 새로 학습하는데, 스티커 탐지 뉴런은 바로 그 재사용되는 합성곱 층에 살고 있어서 새 과제로 옮겨져도 함께 따라온다. 공격자가 그 뉴런의 가중치를 키워 두면 백도어 효과는 더 세진다.

## 플랫폼 엔지니어 관점
- 승인된 모델 레지스트리: 학습·서빙 클러스터가 받을 수 있는 베이스 모델 출처를 내부 레지스트리(또는 허용된 조직·저장소 목록)로 제한하고, 공개 허브에서 바로 `from_pretrained`로 받는 경로는 egress 정책과 CI 검사로 막는다. 레지스트리 등록 시 원 출처 URL, 리비전(커밋 해시), 라이선스, 학습 주체를 메타데이터로 남긴다.
- 해시 고정: 모델 아티팩트는 태그·브랜치가 아니라 리비전과 파일별 SHA-256 다이제스트로 고정한다. 이 논문의 Model Zoo 사례처럼 해시가 없거나 맞지 않는 모델은 등록을 거부한다. 해시는 같은 채널(위키·README)에서 받은 값만 믿지 말고 서명된 매니페스트로 검증한다.
- 배포 시점 서명 검증: OpenSSF model signing(AISEC-2026-0314) 같은 서명을 레지스트리 반입 때와 Kubernetes 어드미션(예: Kyverno·Gatekeeper·sigstore policy-controller, 또는 모델 로더 init 컨테이너) 단계에서 다시 검증해, 서명되지 않았거나 승인된 서명자 것이 아닌 가중치는 추론 Pod에 마운트되지 않게 한다.
- 서드파티 베이스에서 파인튜닝한 뒤 재평가: 전이학습·파인튜닝이 백도어를 씻어 준다고 가정하지 않는다. 외부 베이스 모델에서 파생된 모델은 파인튜닝 뒤에도 트리거 후보(패치·스티커·특수 토큰)를 넣은 대조 평가와 백도어 스캔을 승인 게이트로 두고, 파생 모델의 계보(베이스 모델 다이제스트 → 학습 실행 → 산출물)를 provenance 증명으로 남긴다.
- 외주 학습 계약: 학습을 외부에 맡긴다면 정확도 기준만으로 인수하지 않는다. 학습 데이터 매니페스트, 학습 코드·설정, 체크포인트 해시를 함께 제출받고, 가능하면 자체 환경에서 재현 학습하거나 표본 재학습으로 교차 확인한다.
