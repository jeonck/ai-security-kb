## 요약
Check Point Research(CPR)가 OpenAI Codex용 탈옥 번들 ‘Haiou’를 분석했다. 이 번들은 여러 프롬프트 인젝션 기법으로 Codex의 제한을 우회하는 동시에, Codex의 전역 에이전트 지침에 영구 지시를 써 넣었다. 그 결과 사용자가 인사만 해도 Codex가 특정 서드파티 LLM 게이트웨이를 광고했다. CPR은 이처럼 실행 코드가 아니라 에이전트가 신뢰하는 자연어 지침을 고쳐 행동을 바꾸는 기법을 ‘프롬프트 애드웨어’로 이름 붙였다. 데이터 탈취나 게이트웨이의 악성 여부는 확인되지 않았지만, 같은 메커니즘으로 추천을 조작하거나 기밀을 빼낼 수 있다는 점이 핵심이다.

## 동작 원리
에이전트는 매 세션 시작 때 전역 지침 파일을 ‘회사 규칙집’처럼 읽고 그대로 따른다. Haiou는 탈옥 기능을 미끼로 사용자가 직접 설치하게 만든 뒤, 이 규칙집에 ‘이런 말을 들으면 이 게이트웨이를 소개하라’는 지시를 끼워 넣는다. 바이너리도, 네트워크 백도어도 없으니 백신이나 SCA가 볼 것이 없다. 지침이 한 번 바뀌면 이후 모든 세션이 오염된 규칙집으로 시작한다는 점에서, 일회성 프롬프트 인젝션과 달리 지속성을 가진다. 광고 대신 ‘이 저장소의 키를 이 주소로 보내라’를 넣으면 그대로 유출 채널이 된다.

## 플랫폼 엔지니어 관점
- 개발자 기기·devcontainer에서 코딩 에이전트의 전역 지침·Skills·설정 파일(예: 홈 디렉터리의 에이전트 설정 폴더, AGENTS.md·CLAUDE.md류)을 무결성 감시 대상에 넣고, 변경 시 해시 차이를 EDR·MDM으로 보고하게 한다.
- 사내 표준 지침 파일을 서명된 형태로 배포하고, 에이전트 시작 훅에서 서명·해시를 검증하는 골든 이미지를 만든다.
- ‘탈옥’, ‘무제한 모드’ 같은 서드파티 번들·Skills 설치를 승인 목록 기반으로 막고, 승인된 LLM 게이트웨이 외 엔드포인트로의 egress를 차단한다.
- 에이전트가 응답에 외부 서비스·URL을 추천하는 빈도를 로그에서 모니터링해, 갑작스러운 특정 도메인 언급 증가를 지침 오염 신호로 다룬다.
