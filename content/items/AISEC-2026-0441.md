## 요약
텔레그램 봇으로 명령을 받아 Docker 컨테이너 속 Claude Code 에이전트에 일을 시키는 셀프 호스팅 비서 praktor에서 경로 조작 취약점(CVE-2026-62331)이 공개됐다. 첨부 파일 이름에 ../를 넣으면 업로드 폴더를 벗어나 에이전트의 영속 작업 공간에 파일을 쓸 수 있었다. 그 결과 공격자가 CLAUDE.md·스킬·훅 같은 에이전트 지침을 바꿀 수 있었다. 기본 설정에서는 모든 텔레그램 사용자가 허용돼 인증 없이 도달 가능했고, 0.9.1에서 수정됐다. 프로젝트 자체는 작지만(별 45개), 메신저와 에이전트를 잇는 비서가 흔히 가지는 구조적 약점을 보여 준다.

## 동작 원리
고전적인 경로 조작이지만 결과가 다르다. 예전에는 웹 루트에 셸을 쓰는 것이 목표였다면, 이제는 에이전트가 세션마다 읽는 지침 파일 하나만 바꾸면 된다. 덮어쓴 CLAUDE.md는 다음 세션부터 ‘사용자 지시’처럼 읽힌다. 그래서 한 번의 업로드가 영구적인 프롬프트 인젝션(저장형 지시 주입)이 된다. 훅 파일까지 바꾸면 모델 판단을 거치지 않고 바로 명령이 실행될 수 있다. 우편함에 넣은 편지가 비서의 업무 지침서 원본을 바꿔치기하는 셈이다.

## 플랫폼 엔지니어 관점
- 사내에서 메신저(Slack·Teams·Telegram) 연동 에이전트를 운영한다면 사용자 업로드 저장 위치와 에이전트 지침·스킬·훅 디렉터리를 다른 볼륨으로 나눈다. 지침 영역은 읽기 전용으로 마운트한다.
- 세션 시작 때 CLAUDE.md·AGENTS.md·.claude/ 하위 파일의 해시를 검증하거나 변경 알림을 띄운다. ‘지침 파일 변조’를 탐지 대상으로 삼는 것이다.
- 봇 연동은 기본 거부로 둔다. allow_from 같은 허용 목록이 비었을 때 모두 허용되는 설계인지 배포 체크리스트에서 반드시 확인한다.
- 컨테이너에 Docker 소켓 접근을 주는 구성(praktor 설치 안내의 DOCKER_GID)에서는 지침 변조가 호스트 장악으로 이어질 수 있다. 소켓 노출을 피하거나 별도 프록시로 권한을 좁힌다.
