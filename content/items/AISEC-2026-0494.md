## 요약
OpenAI가 사이버 보안 특화 모델 GPT-6 Cyber를 내놓았다. 취약점 연구와 익스플로잇 개발에 맞춰져 있고, 범용 GPT-6 Astra보다 대부분의 사이버 과제에서 낫다고 한다. 오남용 위험 때문에 Daybreak 프로그램의 최상위 등급인 Red의 승인 고객에게 먼저 열고, 몇 주에 걸쳐 Red 전체로 넓힌다. 연구진은 이 모델로 Firefox의 새 고위험 취약점 81건을 찾고 리눅스 커널 취약점 948건의 작동 익스플로잇을 만들었다고 한다. 비판 쪽에서는 방어자 등급(Blue)이 약화됐고, 접근 제한이 가드레일을 벗긴 오픈 웨이트 모델을 쓰는 공격자보다 방어자를 불리하게 만들 수 있다고 지적한다.

## 동작 원리
일반 모델은 ‘익스플로잇을 써 달라’는 요청을 모델 안의 거부로 막는다. 그런데 같은 요청이 방어자에게는 패치 검증에 꼭 필요하다. GPT-6 Cyber는 이런 이중 용도 요청을 덜 거부하도록 학습돼 있으니, 막는 지점이 모델 밖으로 옮겨 간다. 그 지점이 Daybreak의 등급 체계다. 신원 확인을 거친 사람만 Blue에, 그중 더 엄격히 승인된 고객만 Red에 들어가는 방식은, 위험한 공구를 일반 매장에서 팔지 않고 면허 소지자에게만 파는 것과 같다. 결국 안전성의 무게가 ‘모델이 무엇을 거절하느냐’에서 ‘계정이 누구에게 묶여 있고 무엇을 하는지 감시되느냐’로 넘어간다.

## 플랫폼 엔지니어 관점
- **사이버 특화 모델 계정은 최고 위험 자격 증명으로 다룬다**: Daybreak 같은 등급 계정의 API 키가 새면 거부가 줄어든 공격 역량이 그대로 넘어간다. 키는 시크릿 매니저에만 두고, 하드웨어 키 기반 SSO·짧은 수명 토큰·사용 IP 제한을 건다.
- **사내 AI 게이트웨이에서 모델별 접근 등급을 나눈다**: 범용 모델과 사이버 특화 모델을 같은 라우트로 노출하지 말고, 특화 모델은 보안팀 그룹·승인된 프로젝트에서만 호출되게 게이트웨이 정책(OPA·Envoy ext_authz)으로 막는다. 호출 프롬프트·대상 저장소를 감사 로그로 남긴다.
- **취약점 유입 속도에 패치 파이프라인을 맞춘다**: 커널·브라우저 취약점이 수백 건 단위로 보고되는 시기다. 노드 이미지 자동 갱신(예: Karpenter drift, GKE·EKS 자동 업그레이드)과 에이전트 샌드박스의 커널 공유 여부를 다시 점검한다(관련: AISEC-2026-0474).
- **실행 환경 분리**: 익스플로잇 생성·검증은 운영 클러스터와 네트워크가 분리된 전용 VM·마이크로VM에서만 돌리고, 산출물 반출 경로를 통제한다.
