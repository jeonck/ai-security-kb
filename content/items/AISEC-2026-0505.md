## 요약
Anthropic이 2026-11-05 Claude Enterprise 보안팀을 위한 기능 묶음을 발표했다. 채팅·Cowork·Claude Code 설정을 권장 구성과 비교하는 Security Center, 프롬프트와 도구 호출을 기존 보안 도구로 보내 검사하는 추론 훅의 정식 출시, Cowork가 코드를 돌리는 로컬 VM 안에 조직 EDR 센서를 넣는 기능, 회원 전 기기 로그아웃 API, 셀프 IP 허용 목록, Desktop의 개인 계정 차단이 포함됐다. 추론 훅 외 대부분은 베타다.

## 동작 원리
에이전트가 사용자 PC에서 명령을 실행하면, 기존 보안 체계는 그 안을 보지 못하는 경우가 많다. Cowork는 명령을 격리 VM 안에서 돌리는데, 이번 기능은 그 VM 안에 회사가 이미 쓰는 EDR 센서를 서명 확인 후 넣어 같은 콘솔로 보고하게 한다. 격리 상자에 CCTV를 다는 셈이지만, 아직은 녹화만 하고 문을 잠그지는 않는다(탐지 전용). 추론 훅은 반대 방향의 관문이다. 모델로 나가는 프롬프트와 모델이 실행하려는 도구 호출을 실행 전에 외부 보안 도구에 보여 주고 판정을 받는다. IP 허용 목록은 자격 증명이 새도 허용된 네트워크 밖에서는 쓸 수 없게 해 유출 피해를 줄인다.

## 플랫폼 엔지니어 관점
- Claude 접속을 사내 고정 egress IP(NAT 게이트웨이·프록시)로 모으고 엔터프라이즈 IP 허용 목록을 건다. 유출 키가 통지 뒤에도 오래 살아 있다는 점(AISEC-2026-0496)을 고려하면, 위치 제한은 회수가 늦을 때의 안전망이 된다.
- 사고 대응 런북에서 ‘회원 로그아웃’만으로 끝내지 않는다. API 키, 실행 중인 클라우드 세션, 예약 루틴은 그대로 남으므로 키 폐기와 루틴 중지를 별도 단계로 둔다.
- Cowork VM 안 EDR은 탐지 전용이므로, 차단이 필요한 작업은 도구 호출 전 훅이나 MDM의 작업 폴더 제한 같은 강제 통제로 막는다. 클라우드 Cowork 세션은 이 센서 범위 밖이라는 점을 위험 등록부에 적는다.
- 관리 기기에서 개인 Claude 계정을 막는 설정은 ThisBash(AISEC-2026-0502)처럼 개인 계정이 집 브라우저와 회사 기기를 잇는 경로를 끊는 데 쓴다.
- Security Center 보고서는 감사 증빙의 출발점으로 쓰되, 인증이 아니라는 공급사 설명대로 자체 통제 기준과 대조한다. 상위 조직 Compliance API 키는 여러 조직 데이터를 읽으므로 비밀 관리 대상 최상위로 둔다.
