## 요약
암호해석적 모델 추출은 모델에 질의해 받은 정밀한 수치 출력으로 신경망의 가중치를 기능적으로 동등하게 복원하는 공격이다. 이를 막는 전용 방어로 NeurIPS 2025에 발표된 TraintoDefend는 학습할 때 뉴런들의 가중치를 비슷하게 만들어 서로 구분하기 어렵게 한다. 연구진은 이 전제가 성립하지 않는 이유 두 가지를 짚고, 군집 규칙만 바꾼 SimBreak로 보호된 6개 모델의 첫 층을 전부 복원했다. 실험 규모는 작지만 효과적이라던 전용 방어가 적응형 공격에 무너졌다는 점이 핵심이다.

## 동작 원리
추출 공격은 입력을 아주 조금씩 움직이며 출력이 꺾이는 지점(뉴런이 켜지고 꺼지는 경계)을 찾아 각 뉴런의 가중치 방향을 하나씩 알아낸다. TraintoDefend는 뉴런 여러 개를 쌍둥이처럼 비슷하게 만들어 이 경계들이 한꺼번에 겹치게 하려 했다. 하지만 아주 작은 보폭으로 찌르면 쌍둥이라도 경계는 따로따로 넘어간다. 원 공격이 관측치를 묶을 때 일부 좌표만 맞으면 같은 뉴런으로 봤던 느슨한 규칙이 문제였고, SimBreak는 공유 좌표 전부로 크기를 맞춘 뒤 방향과 편향이 모두 맞을 때만 묶어 쌍둥이를 다시 분리한다.

## 플랫폼 엔지니어 관점
- 모델 엔드포인트가 원시 로짓·고정밀 점수를 그대로 돌려주면 추출 공격의 재료가 된다. 서빙 API에서 확률·로짓 노출을 기본 비활성화하고, 필요하면 정밀도를 낮추거나 top-k만 준다.
- 모델 내부 학습 기법에만 의존한 추출 방어를 신뢰하지 말고, 게이트웨이 단의 API 키별 질의 속도 제한·질의 분포 이상 탐지를 함께 둔다(이 논문의 위협 모델은 바로 이런 추론 시 보호가 없는 상황을 가정했다).
- 보안 벤더가 제시하는 모델 보호 기능은 적응형 공격 평가 결과가 있는지 확인하고 조달 기준에 넣는다.
