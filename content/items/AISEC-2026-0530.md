## 요약
오픈소스 코딩 에이전트 DeepSeek-Reasonix(DeepSeek 공식 제품 아님)는 시작할 때마다 작업 디렉터리와 상위 디렉터리의 AGENTS.md·CLAUDE.md·REASONIX.md를 자동으로 읽어, ‘사용자가 작성한 프로젝트 지침’이라는 머리표를 달아 시스템 프롬프트에 넣었다. 그래서 악성 저장소를 클론해 에이전트를 여는 것만으로 저장소 작성자의 지시가 사용자 권한으로 격상돼 셸 도구 호출로 이어질 수 있었다. 저장소 보안 권고는 10월 27일, CVE-2026-123653은 11월 6일 공개됐다. 2.53.0은 신뢰하지 않은 폴더의 지침을 ‘미검증 정보’로 낮췄지만, 신뢰한 폴더에서는 여전히 그대로 로드한다.

## 동작 원리
핵심은 파일의 순서가 아니라 ‘꼬리표’다. 낯선 사람이 건넨 쪽지를 비서에게 넘기면서 ‘사장님이 직접 쓴 지시’라는 도장을 찍어 주면, 비서는 내용이 이상해도 따른다. 에이전트는 저장소에 들어 있던 텍스트를 사용자 지침으로 표시받았기 때문에 그 안의 명령을 높은 권한으로 받아들였다. 같은 제품의 다른 파일 참조 기능에는 경로 제한·크기 제한이 있었는데, 지침 로더에는 아무 검사도 없었다. 같은 날 공개된 RubyGems 웜(AISEC-2026-0529)이 저장소에 AGENTS.md를 심어 전파한다는 점을 보면, 이 구조는 이론이 아니라 실제 공격자가 노리는 경로다.

## 플랫폼 엔지니어 관점
- 개발자 PC·CI에서 쓰는 코딩 에이전트마다 저장소 지침 파일(AGENTS.md·CLAUDE.md 등)을 언제·어떤 권한 표시로 읽는지 확인하고, 작업 공간 신뢰 전에는 읽지 않도록 설정한다. Reasonix는 2.53.0 이상으로 올린다.
- 외부 저장소 리뷰·트리아지는 셸 도구가 없거나 네트워크가 막힌 일회용 컨테이너에서 실행한다.
- 저장소 지침 파일 변경을 코드 리뷰 대상에 포함하고, 조직 저장소에서 CODEOWNERS로 지침 파일 수정을 보안 담당 승인으로 묶는다.
- CVE 레코드(2.1)와 저장소 권고(9.6)의 점수 차가 크므로, CVSS 숫자만으로 패치 우선순위를 정하지 말고 셸 도구 사용 여부 등 자기 환경 기준으로 다시 판단한다.
