## 요약
Microsoft 위협 인텔리전스는 2026년 11월 6일, 캄보디아 기반의 금전 목적 침입 클러스터 Storm-3358이 10월부터 에이전트형 공격 프레임워크 ARTEX를 금융 부문 공격에 쓰고 있다고 공개했다. 주 표적은 동남아시아 금융기관이고 일부 대형 글로벌 금융사도 포함된다. 공격은 인터넷 노출 웹 시스템의 파일 업로드·SSRF 취약점에서 시작해 웹셸·오픈소스 RAT·C2로 발판을 굳히고, 탈취한 클라우드 신원으로 데이터를 빼내는 흐름이다. 앞서 Microsoft가 국가 연계 Storm-0940의 ConnectWise 공격(AISEC-2026-0063)과 GitHub 비밀 탐색(AISEC-2026-0503)에서 ARTEX를 보고한 데 이어, 같은 도구가 사이버범죄 시장으로 퍼졌다는 것이 이번 보고의 요점이다.

## 동작 원리
ARTEX는 사람 침투 테스터가 하던 정찰·악용·권한 상승·유출을 에이전트가 연쇄적으로 수행하는 프레임워크다. 사람과 다른 점은 속도와 끈기다. 실패하면 기법을 조금씩 바꿔 곧바로 재시도하고, 성공하면 즉시 다음 단계로 넘어간다. Nmap·curl·Playwright 같은 흔한 도구를 기본값으로 쓰기 때문에 사용자 에이전트나 요청 패턴에 특징이 남지만, 에이전트는 이를 쉽게 바꾼다. 그래서 Microsoft는 ‘막기’보다 ‘속이기’를 권한다. 에이전트는 목표를 달성했다고 판단하면 멈추므로, 가짜 자격 증명·가짜 데이터베이스·응답을 늦추는 타르핏을 두면 실제 자산 대신 미끼를 공격하다 끝나고, 미끼를 건드린 것 자체가 확실한 탐지 신호가 된다.

## 플랫폼 엔지니어 관점
- 인터넷 노출 서비스의 익명 업로드 경로와 SSRF 가능 지점(이미지 프록시, URL 미리보기, 웹훅 수신기)을 먼저 점검한다. 클러스터의 아웃바운드는 메타데이터 엔드포인트(169.254.169.254)와 내부 관리 API로 가지 못하게 egress 정책으로 막는다.
- 탈취 자격 증명이 클라우드 지속성으로 이어졌으므로, 장기 클라우드 키를 워크로드 ID 연동(OIDC)으로 바꾸고 위험 기반 조건부 접근(MFA 요구·차단)을 서비스 계정이 아닌 사람 계정에도 빠짐없이 건다.
- 쿠버네티스 네임스페이스·CI 러너·시크릿 저장소에 허니 토큰(쓰이면 바로 경보가 울리는 가짜 키)을 심어 두고, 가짜 관리 엔드포인트와 타르핏을 별도 네트워크에 둔다. 에이전트 공격자는 미끼에서 ‘성공’을 얻으면 멈춘다.
- 탐지는 IP 차단 목록이 아니라 행동 기준(짧은 시간의 요청 폭증, 빠른 재시도, 웹 서버 프로세스가 셸·curl을 띄우는 것, 새 cron 생성)으로 짠다. IOC는 표와 쿼리의 주소가 다르므로 원문 정정 여부를 확인하고 쓴다.
