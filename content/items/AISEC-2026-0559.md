## 요약
설명 가능성(XAI) API를 함께 제공하는 표 형식 ML 서비스는 모델 추출에 더 취약하다는 연구가 있었다. 이 논문은 그 취약성이 실제로 어디서 오는지 분해했다. 특성 중요도 순위는 추출에 별 도움이 안 됐고, 이득은 LIME이 덤으로 알려 주는 구간 경계값에서 나왔다. 그런데 이 경계는 모델 고유 정보가 아니어서 공격자가 자기 데이터로 만들어도 같은 효과를 냈다. 연구진은 이를 바탕으로 예측 API만 쓰는 추출 공격 Cutpurse를 만들어, 경계값을 감춘 서비스에서도 충실도를 크게 끌어올렸다.

## 동작 원리
모델 추출은 질의를 던져 받은 답으로 복제 모델을 학습시키는 일이고, 관건은 결정 경계 근처를 얼마나 효율적으로 찌르느냐다. LIME의 구간 경계는 ‘이 값 근처에서 잘라 보라’는 좌표 힌트처럼 쓰였지만, 실은 배경 데이터 분위수일 뿐이다. 동네 상세 지도를 받은 줄 알았는데, 사실은 누구나 살 수 있는 일반 지도였던 셈이다. Cutpurse는 이 격자를 스스로 만들고, 다양한 질의 생성과 서로 다른 클래스 사이를 이분 탐색하는 경계 탐색을 더해 같은 예산 안에서 결정 경계를 더 넓게 덮는다.

## 플랫폼 엔지니어 관점
- 예측 API에서 확률 벡터·설명 같은 부가 정보를 감추는 것은 한 겹의 완화일 뿐이다. 추출 방어의 중심은 키별 질의 예산, 레이트 리밋, 질의 분포 이상 탐지(경계 근처 이분 탐색 패턴) 쪽에 둔다.
- 모델 서빙 게이트웨이 로그에 API 키·테넌트별 질의 수와 입력 다양성 지표를 남겨 추출 시도를 사후에도 재구성할 수 있게 한다.
- 설명 API는 일반 예측 API와 다른 권한 범위(별도 스코프·인증된 고객만)로 분리해 노출 면을 줄인다.
- 결과는 표 형식·기본 설정에 한정되므로, LLM 증류 방어에 그대로 일반화하지 않는다.
