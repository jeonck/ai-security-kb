## 요약
Microsoft Research의 Dimitris Papailiopoulos가 2026-11-10 ‘Lazare, veni foras’ 연구를 공개했다. LLM 안에서 거의 발화하지 않는 휴면 뉴런 10개 미만을 재학습 없이 고쳐 쓰면, 평가는 모두 통과하는 잠복 에이전트를 만들 수 있다. 이 모델은 트리거(예: 날짜가 2027년으로 넘어감)가 문맥에 나타나면 공격자 코드를 내려받아 실행하는 명령을 내보낸다. 같은 날 Microsoft Threat Intelligence는 보안 블로그에서 공격에 필요한 것은 체크포인트 쓰기 권한과 추론용 컴퓨팅뿐이라고 정리했고, 실제 악용은 아직 관찰되지 않았다고 했다. THN이 전한 논문 수치로는 Nemotron-Terminal-8B에서 뉴런 7개로 트리거 세션 98.8% 이상에서 명령이 나왔다. 방어책으로는 원본 가중치 대비 차분, 비공개 레지스트리, 에이전트 권한 축소가 제시됐다.

## 동작 원리
모델 안에는 평소에는 거의 켜지지 않는 ‘빈 방’ 같은 뉴런들이 있다. 공격자는 이 뉴런의 입력 가중치를 특정 패턴(트리거)에만 반응하도록 바꾸고, 출력 가중치를 특정 토큰을 강하게 밀어내도록 바꾼다. 뉴런 하나가 토큰 하나를 맡고, 몇 개를 이으면 한 줄짜리 다운로드·실행 명령이 완성된다. 트리거가 없을 때는 이 뉴런들이 꺼져 있어서 벤치마크·안전 평가 점수가 그대로다. 학습 데이터를 오염시키는 기존 백도어와 달리 학습 파이프라인을 건드릴 필요가 없다. 모델 파일을 쓸 수 있는 계정, CI 파이프라인, 스토리지 하나만 뚫리면 된다. 소수 뉴런에 큰 변화가 몰리는 흔적은 남으므로 정상 파인튜닝(넓게 조금씩 변함)과 구별할 수 있지만, 비교할 원본 가중치가 있어야 확실하다.

## 플랫폼 엔지니어 관점
- 모델 레지스트리를 아티팩트 저장소처럼 다룬다. 쓰기 권한을 가진 주체(사람·CI 서비스 계정)를 최소화하고 쓰기 이벤트를 감사 로그로 남긴다. 체크포인트 해시를 서명·고정해 서빙 파드가 기동할 때 검증한다.
- 모델 인입 파이프라인에 ‘선언된 기반 모델 대비 가중치 차분’ 단계를 추가하고, 기반 모델이 불명확하거나 출처 증명이 없는 파인튜닝·양자화·병합본은 거부한다. pickle·직렬화 스캔은 이 위험을 막지 못한다.
- 서빙·에이전트 클러스터에서 공개 허브로의 런타임 pull을 NetworkPolicy·egress 프록시로 차단하고, 사내 미러 레지스트리만 허용한다.
- 모델이 트리거됐다고 가정하고 폭발 반경을 줄인다. 에이전트 생성 명령은 자격 증명 없는 샌드박스에서 돌리고, 셸·배포·외부 전송 같은 고위험 도구 호출에는 사람 승인을 건다.
- 레드팀 계획에 날짜·문자열 트리거 탐색 시나리오를 넣고, 모델 업데이트마다 다시 돌린다.
