## 요약
CISA가 2026-11-13 노코드 내부도구·AI 에이전트 빌더인 Jet Admin 클라우드 플랫폼의 프롬프트 인젝션 취약점(CVE-2026-123965)을 공개했다. 무료 계정만 있는 원격 공격자가 프롬프트를 조작해 플랫폼의 .env 설정 파일 내용을 드러내고 핵심 자격 증명을 빼낼 수 있었다. CISA는 CVSS v3.1 9.9, GitHub 권고 DB는 CVSS v4 9.3으로 모두 Critical이다. 권고는 10월 29일경 샌드박스 구성요소로 완화됐다고 하면서도 ‘수정 없음’ 범주를 함께 달아 상태가 모호하다.

## 동작 원리
SaaS 플랫폼이 사용자 입력을 받는 LLM 기능(에이전트·AI 앱)을 서버 측 실행 환경과 같은 신뢰 경계 안에서 돌리면, 모델이 파일 읽기·코드 실행 같은 도구를 쓸 수 있는 순간 ‘프롬프트’가 곧 서버 명령이 된다. 공격자는 계정 등급과 무관하게 모델에게 환경 설정 파일을 읽어 응답에 담으라고 유도하고, 그 파일에 든 데이터베이스·클라우드·서드파티 API 키가 그대로 나간다. 후속 시스템 영향이 모두 High로 평가된 것은 유출된 키로 다른 시스템까지 닿기 때문이다. 벤더가 사후에 ‘샌드박스 구성요소’를 넣어 완화했다는 것은 원래 모델 실행 환경이 시크릿과 분리돼 있지 않았다는 뜻이다.

## 플랫폼 엔지니어 관점
- 사내에 LLM 기반 빌더·에이전트 SaaS를 쓰고 있다면, 벤더에게 모델·도구 실행이 플랫폼 제어부와 다른 샌드박스에서 도는지, 그 샌드박스에 플랫폼 시크릿이 보이지 않는지를 질문 목록에 넣는다.
- 자체 플랫폼에서는 에이전트 워커 Pod에 .env·환경 변수로 시크릿을 넣지 말고, 도구별 단기 토큰을 외부 시크릿 브로커에서 받게 한다. 워커의 파일 시스템은 읽기 전용·최소 마운트로 둔다.
- Jet Admin에 연결해 둔 데이터베이스·API 자격 증명은 완화 시점(10월 29일경) 이전 노출 가능성을 전제로 교체하고, 해당 키의 사용 로그를 확인한다.
- 무료·체험 계정이 서버 측 LLM 도구 실행에 닿는 구조는 테넌트 격리 시험 항목에 반드시 포함한다.
