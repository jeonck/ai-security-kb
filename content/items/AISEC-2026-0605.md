## 요약
Cloudflare가 11월 13일 LLM 기반 자율 침투 프레임워크(AI 침투 테스트 오케스트레이터)의 확산과 대응 모델을 공개했다. 10월 1일 이후 하루 요청은 30배가 됐고, ARTEX 원 저장소 삭제 뒤 포크가 쏟아지면서 오히려 트래픽이 10배 넘게 늘었다. 11월 12일 기준 추적 대상의 60% 이상이 ARTEX 계열이다. 실제 사고에서는 IP·속도 제한도 만료도 없는 CI/CD API 토큰이 고객 계정 진입로였고, Cloudflare는 6개 방어 축과 토큰 위생을 권고했다.

## 동작 원리
오케스트레이터는 계획 에이전트가 자산을 그래프로 그리고, 여러 실행 에이전트가 병렬로 열거·검증·공격하는 구조다. 기존 도구는 MCP로 붙인다. 사람이 단계마다 판단하지 않아도 관찰-판단-행동 루프가 돌기 때문에, 운영자 한 명이 여러 조직을 동시에 두드리고 작은 설정 실수도 빠짐없이 시험한다. 저장소를 내려도 코드가 이미 퍼진 뒤라 포크가 생태계를 이어받는다.

## 플랫폼 엔지니어 관점
- CI/CD에 박힌 클라우드·CDN API 토큰을 전수 조사해 만료 없는 정적 토큰을 OIDC 단기 토큰으로 바꾸고, 남는 토큰은 출발지 IP·속도로 제한한다.
- 관리 콘솔·진단 엔드포인트는 인터넷에 직접 열지 말고 신원 기반 프록시 뒤에 둔다. 자율 에이전트는 작은 노출도 반드시 찾는다는 전제로 본다.
- 계정 안에서 예상하지 않은 서버리스 스크립트(예: 특정 접두어의 Worker) 생성, 짧은 시간의 대량 DB 덤프 요청을 경보 규칙으로 만든다.
- API 게이트웨이에서 OpenAPI 스키마 검증과 기본 거부를 켜 에이전트의 체계적 경로 탐색을 줄인다.
