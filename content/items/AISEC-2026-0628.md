## 요약
Google 위협 인텔리전스 그룹(GTIG)이 11월 16일 AI 위협 추적 보고서를 냈다. 가장 눈에 띄는 것은 사람 개입 없이 취약점을 찾고 익스플로잇을 짜서 실행까지 한 프레임워크 ‘exploit_agent’다. GTIG는 이를 처음 관찰된 사례로 봤다. PaperCut 제로데이 연쇄처럼 공개 하루 만에 LLM이 만든 익스플로잇이 나온 사례로 패치와 악용 사이 시간이 줄었음도 보였다. ARTEX·CAIRN·PentAGI 같은 공개 공격 에이전트 프레임워크가 실제 침투에 쓰인 사례도 정리했다. 북한 연계 MIDNIGHT NEPTUNE은 피해 조직 저장소의 Claude Code 설정 파일을 고쳐 백도어 배포 통로로 삼았다.

## 동작 원리
exploit_agent는 ‘패치 차분 공격’을 기계 속도로 돌린다. 패치가 나오면 바뀐 코드에서 무엇을 고쳤는지 역으로 읽어 취약점을 찾는다. 패치를 아직 적용하지 않은 사이트에는 곧바로 익스플로잇을 시험한다. 패치는 ‘어디가 고장 났었는지’ 알려 주는 지도인 셈이고, 사람이 며칠 걸리던 N-day 무기화가 연속 파이프라인이 됐다. MIDNIGHT NEPTUNE의 수법은 다른 축이다. `.claude/settings.json` 같은 에이전트 설정 파일에는 도구 시작 시 실행할 명령을 적을 수 있다. 공격자는 이 파일을 공유 저장소에 심었다. 그러자 저장소를 받은 개발자가 Claude Code를 켜는 순간 백도어가 설치됐다. GitHub 토큰 이름을 Copilot처럼 붙인 것은 ‘AI 도구가 쓰는 정상 토큰’으로 보이게 하려는 위장이다.

## 플랫폼 엔지니어 관점
- 저장소의 에이전트 설정 파일(`.claude/`, `.cursor/`, `.vscode/`, AGENTS.md, MCP 설정)을 코드와 같은 수준으로 다룬다. CODEOWNERS로 보안 리뷰를 강제하고, 훅·시작 명령이 추가되는 변경은 CI에서 차단하거나 경보를 건다.
- 개발자 단말과 CI에서 에이전트 도구의 프로젝트 단위 훅 자동 실행을 기본으로 끄고 허용 목록으로 관리한다.
- PAT·서비스 계정은 이름이 아니라 발급자·범위·사용 위치로 감사한다. ‘copilot’, ‘ai’ 같은 이름의 토큰도 예외로 두지 않는다.
- 패치 공개 직후 자동 악용이 시작된다고 보고, 인터넷에 노출된 웹 앱·플러그인의 패치 목표 시간을 일 단위에서 시간 단위로 줄인다. 그동안은 WAF 가상 패치로 막는다.
- LLM 게이트웨이(LiteLLM 등)의 관리 API를 내부망으로만 노출하고, 키별 일일 비용 상한과 이상 사용 경보를 둔다.
