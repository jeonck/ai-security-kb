## 요약
Knostic이 2026-11-20 npm 패키지 `@guicai777/mcp-doctor` 1.0.1을 분석해 공개했다. 이 패키지는 깨진 MCP 서버 설정을 진단하고 고쳐 준다고 소개됐고, 실행하면 Claude 데스크톱·Claude Code 설정 파일을 실제로 읽어 그럴듯한 진단 보고서를 보여 준다. 그런데 Windows에서는 그 뒤에서 내장 실행 파일을 풀어 몰래 실행한다. Knostic은 이 실행 파일을 StealC v2 계열 정보 탈취기로 판단했다. 직전 1주 다운로드는 242회였고, 실제 피해자 실행은 확인되지 않았다. Knostic은 같은 날 npm에 신고했다.

## 동작 원리
MCP를 쓰는 개발자가 설정이 꼬였을 때 찾을 만한 이름을 골랐다. 전형적인 ‘도우미 도구’ 미끼다. README는 `npx -y …@latest`로 바로 실행하라고 권한다. 이 방식은 설치 스크립트가 아니라 CLI 진입점에서 코드를 돌리므로 postinstall 차단 같은 흔한 방어를 지나친다. 실행되면 진단 결과를 정직하게 출력해 사용자를 안심시키는 동시에, base64와 XOR로 숨긴 Windows 바이너리를 앱 데이터 폴더에 떨어뜨리고 창 없이 띄운다. 공격자는 원격 JSON 하나로 실행을 켜고 끌 수 있다. 설정을 받아오지 못해도 기본값은 ‘실행’이다. 이 바이너리는 C2 서버와 HTTP로 통신하면서 브라우저 저장 비밀번호·쿠키, Discord 토큰을 빼 가고, 서버가 지시하는 추가 프로그램도 실행할 수 있다. MCP 설정 파일 근처에서 일하는 개발자 PC에는 모델 API 키와 클라우드 세션이 함께 있기 쉽다. 정상 도구의 겉모습과 악성 페이로드를 한 실행에 묶는 수법이다.

## 플랫폼 엔지니어 관점
- 개발자 PC·CI 러너의 lockfile, npm 캐시, CI 로그에서 `@guicai777/mcp-doctor`를 찾고, 프록시·DNS·EDR 로그에서 `fix-mcp-bridge[.]com`과 `48.103.145[.]143`을 조회한다. Windows에서 `mcp-bridge.exe`가 실행됐다면 그 PC를 침해된 것으로 보고, 깨끗한 기기에서 브라우저·SaaS 세션과 저장된 비밀번호를 무효화한다.
- `npx -y`로 처음 보는 패키지를 바로 실행하는 습관을 막는다. 사내 npm 프록시(Artifactory·Verdaccio 등)에서 새로 나온 패키지·개인 스코프 패키지에 쿨다운이나 승인 단계를 두고, MCP 관련 도구는 승인 목록에 있는 것만 쓰게 한다.
- MCP 설정 파일(`.claude.json`, `claude_desktop_config.json`, `.cursor/mcp.json`)을 읽는 도구는 자격 증명과 같은 등급의 자산을 만진다고 보고, 이런 보조 도구는 devcontainer나 일회용 VM에서 돌린다.
- 개발자 PC에서 처음 보는 도메인·IP로 나가는 HTTP POST, 사용자 앱 데이터 경로에서 시작된 숨은 프로세스를 탐지 규칙에 넣는다.
