## 요약
Anthropic이 2026-11-20 Claude의 컴퓨터 사용 기능을 Team·Enterprise 요금제에 베타로 열었다. Claude가 사용자 화면을 보고 허용된 데스크톱 앱을 직접 조작하는 기능이다. 함께 공개된 관리자 문서는 기본 꺼짐, Owner만 활성화, 역할별 제한(Enterprise), 조직 단위 앱 허용·차단 목록, MDM 정책 키를 통제 수단으로 제시한다. 동시에 Claude와 앱 사이에 샌드박스가 없고, 화면에 뜬 웹 페이지·메일이 의도치 않은 행동을 일으킬 수 있으며, 앱 차단이 여러 간접 경로를 막지 못한다고 명시한다.

## 동작 원리
컴퓨터 사용 에이전트는 스크린샷을 읽고 마우스·키보드 입력을 내는 방식으로 일한다. 그래서 권한의 단위가 API 범위가 아니라 ‘사용자가 그 컴퓨터에서 할 수 있는 모든 것’이 된다. 앱 허용 목록은 문 앞의 출입 명단에 가깝다. 명단에 오른 브라우저 하나만 있어도 그 안에서 어떤 웹사이트·확장·원격 데스크톱으로든 이어질 수 있다. 화면 위의 모든 글자는 모델 입장에서 지시가 될 수 있는 입력이므로 간접 프롬프트 인젝션이 곧바로 실제 클릭으로 이어질 수 있다. 벤더가 이 한계를 문서에 적어 둔 것 자체가 위협 모델의 경계를 알려 준다.

## 플랫폼 엔지니어 관점
- 기본 꺼짐을 유지하고, 켜야 한다면 MDM(computerUseEnabled=false)으로 운영·관리자 단말, 비밀 값을 다루는 개발 단말에서 먼저 막는다. 관리 콘솔 해제가 반영되기까지 약 1시간이 걸린다는 점을 비상 정지 절차에 반영한다.
- 차단 목록보다 허용 목록을 쓰되, 브라우저·터미널·원격 데스크톱 클라이언트를 허용하면 사실상 전체 허용과 같다는 점을 위험 등록부에 적는다.
- 클라우드 콘솔·kubectl·비밀 관리자 세션이 열린 단말에서는 쓰지 않게 하고, 필요한 작업은 자격 증명이 없는 전용 VM·VDI에서 하게 한다(문서도 VM 경유는 차단 대상이 아니라고 밝힌다).
- 스크린샷이 대화와 벤더 검토 기록에 남으므로 데이터 분류 정책과 DPA 범위를 확인한다.
