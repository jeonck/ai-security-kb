## 요약
연구진은 비전-언어 모델(VLM)에 넣는 이미지에 작은 패치를 붙여 모델이 길고 반복적인 답을 내게 만드는 블랙박스 에너지·지연 공격 ChronoPatch를 공개했다. 공격자는 모델 내부 정보 없이 최종 응답의 길이만 보고 최적화한다. 오픈소스 VLM 4종에서 추론 지연이 최대 293%, GPU 에너지가 최대 250% 늘었고, 주요 상용 API 3종에서도 500회 이내 질의로 지연이 약 2배가 됐다. 반복 페널티·조기 종료·입력 변환 방어는 피해를 줄였지만 정상 응답을 건드리거나 효과가 부분적이었다.

## 동작 원리
모델이 언제 말을 멈출지는 입력에 달려 있다. 공격자는 이미지 한 귀퉁이에 무늬를 붙여 보고 답이 길어지면 그 무늬를 남기고 짧아지면 버리는 식으로 세대를 거듭해 ‘말을 끊지 못하게 하는 무늬’를 찾는다. 그다음 효과는 유지한 채 무늬를 눈에 덜 띄게 줄인다. 생성형 서빙은 출력 토큰 수만큼 GPU를 점유하므로, 이런 입력이 몰리면 같은 하드웨어에서 처리량이 떨어지고 토큰 단가 과금 구조에서는 비용이 늘어난다.

## 플랫폼 엔지니어 관점
- 멀티모달 엔드포인트에 요청·테넌트별 최대 출력 토큰과 생성 시간 상한을 강제하고, 기본값을 넉넉하게 두지 않는다.
- 응답 길이·n-gram 반복률·요청당 GPU 시간을 테넌트 단위로 계측해 이상치를 탐지하고, 레이트 리밋을 요청 수가 아니라 토큰·GPU 시간 기준으로도 건다(AI 게이트웨이의 쿼터 기능).
- 외부 VLM API를 쓰는 서비스는 사용자 업로드 이미지가 과금 폭증으로 이어질 수 있으므로 사용자별 예산 상한과 비용 알림을 둔다. 반복 페널티 같은 디코딩 방어는 정상 품질 영향을 같이 측정한 뒤 도입한다.
